# v2.3.0 问题回顾队列

版本：v2.3.0 / versionCode 32，2026年11月9日。

本版把日记录中的问题连接到独立的回顾队列。队列是可选的 schema 9 顶层数据，旧备份没有队列时保持原样；历史记录不会被补造为回顾事件。

**已交付**

- 保存日记录时，非空的科目问题按来源日期、科目和原文加入队列；重复保存会去重。
- 手动问题可填写下次回顾日期和关联科目。
- 每个项目保留稳定 ID、来源、问题文字、状态、下一次日期和回顾事件。
- 回顾事件记录反馈类型（独立回忆、看提示后想起、仍不确定）、备注和下一次日期；留空日期会明确结束项目。
- 队列支持暂停、恢复、结束；到期项目集中显示在复盘页面。
- 队列不参与分钟、词数、任务完成或自动评估的数值计算；来源字段用于回看原始记录，不复制学习量。
- Java 与 JavaScript 状态校验同步限制项目、事件、文本和 ID，拒绝未知字段与重复 ID。
