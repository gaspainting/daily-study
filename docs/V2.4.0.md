# v2.4.0 周复盘行动与拾遗 Gate 0 前置接入

版本：v2.4.0 / versionCode 33，2026年11月10日。

**已交付**

- 复盘页根据记录完整率、目标执行率、待处理任务和到期问题生成“下周行动”草案。
- 草案中的延期任务、安排问题回顾和目标检查分别有稳定行动 ID；生成阶段不改写任务、回顾或目标。
- 用户确认后才执行对应任务延期或回顾日期调整；忽略项仍保留在行动方案中，历史周的统计依据不变。
- 顶层 `actionPlans` 严格校验，和 `reviewQueue` 一起兼容 schema 9、备份和恢复。
- “拾遗连接”设置保存自动准备同步、手动地址、配对状态、待同步数量和手动同步状态。
- Android Keystore 设备身份、原子同步状态、协议信封校验、golden fixtures、`daily-study://` 深链和确认提醒本地调度前置代码已加入。

**数据与安全边界**

每日学习没有加入云服务器或任意局域网文件接口。未收到桌面端 ACK 时 outbox 保留，状态显示等待连接；本地提醒只表示已安排，不能替代真实设备上的通知可见性验证。文件、AI 和桌面全景功能仍属于拾遗桌面端。

**验证**

- 完整 Node 测试覆盖任务、问题回顾、周行动、协议版本、去重和冲突样例。
- Java 原生测试构建通过，APK 使用既有签名并通过 v2/v3 签名校验。
- 未连接真实 Android 手机和拾遗桌面端，因此 Gate 0 中的局域网配对、离线 20 条记录、ACK、地址变化、睡眠恢复和未授权设备拒绝仍待现场联调。
