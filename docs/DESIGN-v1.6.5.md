# v1.6.5 总体任务分配与记录操作

**范围**

基线为已发布的 v1.6.4/code21、schema8，修改前工作区干净，178项模型测试通过。沿用白底列表；本轮增加总体分配、编辑内保存、列表单词入口及返回位置。

**总体任务分配**

独立入口位于“计划”页的模块上方，标题为“总体任务分配”。编辑当前计划的单词每日新学、周一至周日参考时间和数量目标。总时间与分项使用已有区间分配算法联动，可将当前星期的时间复制到周一至周五。

生效日期默认今天或计划起始日，不能回溯到过去。修改默认分配及生效日起相关目标；新增日期继续使用新默认。只有修改过的科目、星期参与应用。未修改的时间、课表、实际学习和其他计划继续使用原值。

默认保留单日自定目标，可选择覆盖；词数和数量按与原默认不同的日期值识别，时间使用现有手动标记。应用前显示实际日期、目标数量、评估数量和保留项。已记录日期可按新目标评估，也可保留原依据。重评仅更新本次涉及科目的维度，其他依据和生效日前历史保留。数量单位不同的日期跳过并显示数量。

**实现与数据**

新增allocation.js负责纯模型转换，allocation-ui.js负责集中表单，app.js沿用原生确认、草稿、版本检查和单次保存。使用现有wordGoal、defaults、日期目标和manualReferenceDefaults字段，schema继续为8；Java校验、备份与小组件读取原字段。保存采用当前计划和_revision检查，失败不应用候选状态。

**记录与布局**

单词列表提供独立“记一笔”按钮，调用原分次编辑。科目、安排和随记弹层均增加“保存记录”，提交整个今日表单；成功后返回列表，失败时保留输入并在弹层提供重试。标题“完成”及系统返回仍仅关闭编辑。

页面导航按计划、页面记忆滚动位置，今日另按日期区分。键盘调整视口时滚动到当前字段，沿用Android adjustResize。大字号下快捷操作允许换行。

**验证清单**

- 仅更新涉及维度的评估；空白、0、部分记录、休息和历史单位。
- 取消、写入失败、重复保存、草稿、后台返回、多计划隔离。
- 独立入口、编辑内保存、列表记一笔、窄屏、200%字体、真实软键盘与无障碍名称。
