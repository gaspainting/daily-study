# v1.6.8 归档补录修复

版本v1.6.8 / versionCode 25 / schema9，2026年10月27日已[正式发布](https://github.com/gaspainting/daily-study/releases/tag/v1.6.8)。自动评估主体已随[v1.6.7](V1.6.7.md)发布，本补丁完善补录入口，沿用已有评估依据及启用日期。

**实际改动**

- 已归档科目仍有原计划必需输入时，在对应日期保留编辑入口；缩短计划范围后也能从历史打开并补记。
- 新的历史数量输入使用当时依据中的单位；已有数量、明确的0和原记录单位保留。
- “继续记录”先定位实际缺失的时间分项。
- 查看依据时，移除目标或改变目标单位也显示调整后对照。

问题先在正式同源v1.6.7测试包中复现，失败输出见[补录入口基线](validation-v1.6.7/archived-inputs-before-console.txt)。修复没有重新启用科目，也没有减少原计划分母。
