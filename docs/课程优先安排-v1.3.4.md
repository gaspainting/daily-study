# 课程优先安排 · v1.3.4

先回顾当天课程，再安排考研高数复习。每天根据空课、作业和实际精力选择时段，可分段进行；不固定起止钟点。单词利用碎片时间按数量记录，沿用当前新学目标，复习另记。

**每日参考量**

| 日型 | 课程复习 | 考研高数 | 合计 |
|---|---:|---:|---:|
| 工作日：当天3门及以上固定课程 | 40分钟 | 50分钟 | 90分钟 |
| 工作日：当天0—2门固定课程 | 30分钟 | 60分钟 | 90分钟 |
| 周六 | 60分钟 | 30分钟 | 90分钟 |
| 周日早间 | 30分钟 | 30分钟 | 60分钟 |

这里按当天固定课的门次区分课多、课少，每次课为两节。周末集中回顾本周课程，周日下午留作休息。工作日20:30起、周末09:30前与19:00起沿用原有休息边界。

**课程复习怎么用**

1. 先整理当天笔记中的概念、公式和例题，标记没有理解的地方。
2. 处理与当天课程相关的作业或回顾一道代表性例题。
3. 再使用剩余参考量进行考研高数复习。具体教材、章节与周目标自行填写。

当天无固定课时，回顾近期笔记和作业。周六集中整理本周课堂笔记、例题与作业；周日早间回顾易错点和未理清的问题。

**在 App 中使用**

今日页“复习顺序”显示课程复习、高数和单词目标。课程复习可以计时，也可以直接填写实际分钟、内容和问题。单词继续使用“新学”“复习”数量字段。

原70天默认计划在升级后，从2026年10月15日与读取当天中较晚的一天开始加入课程复习。过去日期的参考量和记录保留。已修改的未来高数参考量沿用原值；需要统一采用新安排时，到“计划 → 课程优先安排”查看日期范围，再点击“应用安排”。此操作替换该范围内课程复习和高数的参考量。其他独立计划保留原安排，可在各自计划中选择应用。

每天的参考量仍可单独修改。每周目标继续由你填写。
