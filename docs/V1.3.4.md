# v1.3.4：课程复习优先，灵活安排

已发布1.3.4，versionCode 8，日期2026年10月15日。基线为main的80a0ef6（v1.3.3源码），修改前工作区干净。技术栈仍为Java Activity、WebView与随APK打包的HTML/CSS/JS。

**完成内容**

今日增加课程复习科目和“复习顺序”。工作日课程与考研高数合计90分钟，课多日40＋50分钟，课少日30＋60分钟。周六集中回顾60＋30分钟；周日早间30＋30分钟，下午休息。每天自行选择时段，不设置每日起止钟点。单词继续按新学与复习数量记录，自填周目标沿用。

课表采用原交接说明第4节的课程、星期、起止周与单周条件。2026年10月12日对应第7教学周。>=3门次为课多日，其余为课少日；无固定课日回顾近期课程。原70日参考表保留作为历史输入。

默认计划从max(2026-10-15、读取当天、计划起日)开始分配。过去参考、实际记录、休息状态、用户周目标、单词目标及计时会话保留。用户已修改的未来高数参考量不自动替换；缺少目标时保留原自定默认量。其他独立计划不自动采用新安排。“计划 → 课程优先安排”展示日期与替换范围，确认后可统一应用课程和高数的参考量。

**文案与布局**

新增区块只列顺序、参考量和课程名称；周日使用“早间参考量”。课程问题字段移除高数示例。应用前明确所示日期内的参考量会被替换；取消不写入，保存失败保留预览，成功后显示“安排已更新”。没有加入存储方式、缓存实现或固定作息的常驻说明。移除相邻重复分隔线。
