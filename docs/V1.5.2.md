# v1.5.2：启动检查更新

2026年10月19日，versionCode15。基线为已发布v1.5.1/code14，main be1b8ae；开始时工作区干净。

**使用变化**

重新启动App时检查GitHub发行清单。发现新版后，在启动阶段展示版本说明、下载及“稍后”，使用原有更新下载和Android安装入口。后台返回、Activity重建和同一页面重复初始化不发起新的启动检查。

“稍后”、关闭及系统返回只结束本次自动提示，页头保留更新入口。检查完成较晚时，若主页面已有未保存输入、主弹层已打开或App已进入后台，则保留页头入口，避免替换当前界面。无新版或检查失败时继续原启动过程。下载和安装由用户主动发起。

安装前检查未保存表单和活动计时；可取消、保存计时后继续，或确认丢弃计时。下载完成、申请安装权限、打开安装器仍显示各自状态，实际版本来自PackageInfo。数据格式仍为schema6。

v1.5.1及更早版本需先从“设置 → 关于”更新至本版，之后的冷启动才具备自动检查。
