# 每日学习 v1.6.0

2026年10月22日，versionCode17。数据格式仍为 schema6，旧版记录、备份和分钟科目继续使用原字段。

## 数量科目

- 计划 → 科目与目标 → 添加新科目可选择“时间（分钟）”或“数量”。数量科目必须填写单位，例如“题”“页”“组”。
- 数量科目使用周一至周日的整数目标，并可在“修改某一天目标”中单独调整当天目标；分钟科目继续使用参考区间。
- 今日记录对数量科目显示独立的实际数量输入，不显示计时按钮。空白、0 和已填写数量分别保留。
- 数量目标单独评估：低于目标为未完成，达到目标为完成，超过目标为超额；减量使用目标的50%，仅回顾和休息沿用原安排语义。
- 记录保存当时的单位。之后修改科目单位只影响新记录，历史记录仍显示原单位。
- 周复盘、月历、历史筛选、小组件、CSV/PDF报表分别显示数量、目标和单位，不把数量加进分钟总时长。
- ZIP与JSON备份继续保存数量科目、日期目标、数量记录和历史单位；旧备份没有数量字段时按原模型读取。

## 主要修改

| 文件 | 内容 |
|---|---|
| `model.js` / `DataStore.java` | 数量科目、日期目标、数量记录、历史单位与严格校验 |
| `reference.js` / `Reference.java` | 数量目标捕获、独立评估、依据兼容 |
| `app.js` / `tracking.js` | 添加科目、目标编辑、今日录入、历史/月历/评估展示 |
| `schedule.js` / `CourseSchedule.java` | 自动分钟区间生成时跳过数量科目 |
| `StudyWidget.java` / `ReportExport.java` | 小组件与CSV/PDF数量展示 |
| `tests/quantity-model.test.cjs` / `FeatureModelTests.java` | 数量模型、空值与0、单位归属、评估、组件和校验回归 |
