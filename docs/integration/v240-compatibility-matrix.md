## 兼容承诺

- 不修改 v2.4.0 标签、Release、APK、签名或 `latest/update.json`。
- 不强制迁移 Java/WebView/JSON；云同步关闭或不可用时，本地记录和正式保存继续工作。
- 旧 `sync-state.json` 中的局域网元数据只迁移到原生私有标记，不再返回设置页，也不删除学习数据。
- 未知协议、命令、会话失效和服务端冲突都保持显式状态；不把请求发出或本地写入显示成云端确认。
