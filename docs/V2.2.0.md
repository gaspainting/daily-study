# v2.2.0 每日任务执行与安排历史

版本：v2.2.0 / versionCode 31，2026年11月9日。

本版把「周目标中的任务文字」扩展为可以按日期执行的任务实体。任务继续保存在现有 `plan.weekTasks` 中，兼容 schema 9 和原有周目标备份；新增字段均为可选字段，旧数据读取时按原周分组推导安排日期。

**已交付**

- 任务可填写安排日期、截止日期、关联科目和估计分钟。
- 今日页显示当天任务，可在保存前调整顺序、完成、跳过和恢复；跳过不等于完成。
- 计划页提供任务安排入口，可按日期查看和调整任务。
- 延期保留同一任务 ID，并追加 `created`、`edited`、`rescheduled`、`completed`、`reopened`、`skipped` 历史事件；过去未完成的安排只进入待处理提示，不自动补成完成。
- 任务状态与学习记录分开保存。勾选任务不会写入分钟、词数、课程复习或每日记录。
- `weekly-goals.js`、`WeeklyGoals.java`、备份所用状态校验都接受新增字段，仍限制每周 50 项、每项 500 字、估时 0—1440 分钟、历史最多 200 条。

**验证**

- `node --check app/src/main/assets/task-model.js`
- `node --check app/src/main/assets/weekly-goals.js`
- `node --check app/src/main/assets/app.js`
- `node --test tests/task-model.test.cjs tests/weekly-goals.test.cjs tests/model.test.cjs`
- 完整 Node 测试和 Android 构建在发布前再次执行，结果写入发行记录。

当前未连接真实 Android 设备或桌面端，因此本版报告覆盖模型、原生编译和静态 UI 逻辑；设备上的 WebView 触控与跨设备同步不在本版范围内。
