# v1.7.0 架构边界与规则契约

v1.7.0 整理了 WebView 页面、领域规则、原生桥接与 JSON 存储之间的边界。现有功能与数据格式继续使用 schema 9，自动评估口径不变。

## 改动

- 页面状态读写经过领域入口，保存与评估日程使用版本化原生桥接请求。
- 桥接校验请求字段、计划 ID 和预期修订号；重复请求可复用成功结果，过期或内容冲突的请求不会覆盖现有状态。
- 存储端口封装稳定读取、UI读取、状态保存与评估日程保存，当前仍由既有 `DataStore` 实现。
- Java 和 JavaScript 共用规则样例，核对自动评估、时间目标、课程日程、迁移与桥接输入。
