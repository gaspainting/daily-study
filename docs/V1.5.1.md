# v1.5.1：设置页使用手册

2026年10月19日。发行版本1.5.1 / versionCode14，基线为已发布v1.5.0，main e6906fa；开始时工作区干净。

**内容与交互**

设置页顶部新增“使用手册”。12章覆盖今日记录与草稿、计时与休息、单词、周目标、课表与逐门复习、参考与评估、复盘历史、计划科目、日签、提醒小组件、备份报表及更新。

手册随APK提供，离线可读；点击目录打开对应章节，章节可展开/收起，顶部保留目录和关闭操作。系统返回键先关闭手册。打开手册不提交表单，也不清除尚未保存的设置输入。

内容按已实现功能编写，保留必要的空白/0、手动保存、休息边界、备份覆盖、卸载数据删除等说明。没有账号、联网帮助服务或新的权限。

**修改文件**

- app.js：设置入口、手册打开、目录定位及返回；沿用原弹层和返回机制。
- manual.js：章节内容与阅读操作；manual.css：黑白排版、固定阅读控件和大字号适配。
- index.html：加载手册资源；AndroidManifest.xml：1.5.1/code14。
- tests/manual-ui.cjs：真实Android WebView中的阅读、输入保护、离线和无障碍布局检查。
- 使用说明、规划及文案审计更新。学习数据格式仍为schema6，记录、评估、权限及计时逻辑未改。
