# v1.5.0 相关代码审查

基线 v1.4.2/code12，main 232f5d1，开始时工作区干净。Java Activity + WebView 内的原生 JavaScript、HTML/CSS；使用 build.ps1 调用 Android SDK/JDK，没有 Gradle 或前端框架。

**执行清单**

1. 核对 NEXT-STAGE-PLAN、原课表、schema5、保存与草稿机制及当前发行来源。
2. 实现分日期生效的课表、单次调课、逐门复习和周任务关联。
3. 对齐 Java/JS 校验和迁移，保留旧 JSON/ZIP 及正式记录语义。
4. 验证实际 WebView、原生持久化、故障恢复、覆盖升级、报表与大字号布局。
5. 核对构建版本、签名、正式资源、源码清单及公共更新通道。

**模型与保存**

- schema6 在 plan 增加可选 courseSchedule，在根对象增加可选 courseReviews。schema1—5 仍可读取，读取只迁移视图。原有 subjects、records、reviews、assessmentBases、周任务存储结构不变。
- courseSchedule.versions 为有序生效快照，每版保存 from、anchor（周一）、startWeek 和 courses。课程保存稳定 ID、名称、星期、起止教学周、单双周、节次。修改从今天及之后生效；之前的版本保留。已有未来版本时编辑最新版本，生效日不能早于该版本。
- 原默认 70 日计划迁入原学期课表，节次与交接说明第4节核对。补齐周五毛概第1—3周单周条目，原70日期的参考数据不变。其他计划从空课表开始，各计划独立。
- changes 只修改一个原课程日期，可移至另一天或停课。重复来源、缺失原课程、非法日期和重复 ID 被拒绝。已发生的调整保留；未发生的调整可确认撤销。编辑课表不能使已有调课失去原课程。
- courseReviews 保存课程 ID、来源日期、名称和节次快照、勾选、笔记、关联周任务的日期/ID/标题快照。保存过的行保留当时名称，调整课表不删除它们。周末按本周课程名称去重；额外移入课程保留来源日期。
- 复习勾选和笔记使用独立表单与保存按钮，不创建或改写学习分钟、词数、今日安排、周任务完成状态及评估依据。新建计划 API 拒绝携带已有课程复习历史。
- 清单保存对 done、note、task 做三方合并，不冲掉并发修改的其他字段；同字段冲突拒绝覆盖。课表/调课编辑绑定计划和课表快照；并发更改课表拒绝保存，其他原生时长更新在最新状态中保留。
- 正式保存沿用 AtomicFile、修订号、原生验证及写后读取。失败保留输入和重试；成功后才显示结果，重复保存同一清单不新增写入。

**交互、布局与来源**

- 保留黑白、细线及原字体。新增控件有可见标签；没有新增常驻解释、口号、权限或网络依赖。真实错误与恢复覆盖范围在操作场景中显示。
- 开发中发现通用弹层会在保存锁生效时拒绝打开，导致课表保存后无法返回列表。保存成功后的内部跳转使用明确的保留上下文入口；一般导航仍执行草稿检查。
- 动态课程行序列化至隐藏草稿字段，恢复后重建行；手动保存才提交正式课表。后台返回和进程重启均验证。
- Java 课表查询不再克隆整个学习状态，只在缺少课表的旧视图中初始化最小计划副本，避免按日期应用区间时反复复制全部历史。
- “按课表调整”继续复用原有区间预览与覆盖确认；编辑课表本身不替换参考区间。固定休息边界、暂停计时规则和评估规则保留。

**备份、报表与兼容**

- 完整 ZIP 容器仍为格式2，携带各计划的课表与课程复习快照。旧 JSON 恢复只替换当前计划，新 ZIP 的全部计划替换确认明确包含课表、课程复习和周任务。
- CSV 前23列顺序保留，末尾追加“逐门课程复习”；PDF增加对应字段。已归档课程复习科目仍导出已保存清单。独立课表没有课程复习时长科目时，全科报表也携带清单。
- 含 courseSchedule/courseReviews 的 schema6 备份需要 v1.5.0 或更新版本读取；不降级伪造旧格式。
- 日签来源、提醒权限、更新下载、小组件与通知逻辑未新增行为；实际回归范围和限制在版本报告列明。
