# v1.5.0 开发与验证

2026年10月19日。versionName 1.5.0 / versionCode 13。基线为 v1.4.2/code12，main 232f5d1；修改前工作区干净。开发、正式构建及下列验证已完成，正在发行。

**功能与入口**

| 功能 | 入口与行为 |
|---|---|
| 课表编辑 | 计划 → 课程表 → 编辑课表；名称、星期、节次、起止教学周、单双周、周一锚点与教学周编号 |
| 生效日期 | 从今天及之后生效，先前版本保留；最新未来版本可继续编辑 |
| 临时调课/停课 | 选择原日期和课程，移到另一天或停课；未发生的调整可确认撤销 |
| 逐门复习 | 今日 → 复习顺序；逐门勾选、复习笔记及手动保存 |
| 周末回顾 | 汇总本周截至当天的课程，同名去重，保留来源日期 |
| 周任务关联 | 清单可选择本周任务，保存关联与名称快照；显示任务的正式完成状态 |
| 草稿与计划 | 清单、动态课表行可恢复草稿；各计划独立，新计划从空课表开始 |
| 备份与报表 | 完整备份携带课程数据；CSV追加第24列“逐门课程复习”，PDF增加对应内容 |

复习清单、学习分钟、单词数量和周任务完成状态分别保存。编辑课表本身不替换参考区间；“按课表调整”沿用区间预览与覆盖确认。时长评估、休息边界、旧记录统计口径及日签逻辑保留。

**实际修改**

- 新增 courses.js、Courses.java：课表版本、单次调整、复习快照、严格校验及旧数据迁移；Java查询避免复制完整历史。
- 新增 course-ui.js、courses.css，修改 app.js、index.html：入口、表单、草稿、保存、任务关联、返回与窄屏布局。
- model.js、DataStore.java：schema6，继续读取schema1—5，读取不写回；新增数据不改变原记录结构与枚举。
- schedule.js、CourseSchedule.java、生成数据与原始课表：按编辑后的课程判断当日课程、单双周及忙闲参考安排；原70日期的数据不变。
- PlanStore.java：新计划接口拒绝夹带既有复习历史。
- ReportExport.java：保留CSV前23列并追加清单，PDF输出笔记和关联任务；归档科目及无课程时长科目的独立课表也能导出清单。
- MainActivity.java：备份恢复的覆盖范围明确列出课表、课程复习和周任务。
- AndroidManifest.xml：1.5.0/code13；包名、权限、原签名沿用。
- tests、使用说明、规划、文案审计及发布材料同步维护。布局回归脚本改用Base64传输夹具，并明确选择夹具所在周，避免依赖运行日期。

实现与关键决策见[代码审查](CODE-REVIEW-v1.5.0.md)，文案及出现条件见[文案审计](ux-copy-audit.md)。

本轮未执行 vivo X100s 真机操作、TalkBack 实际朗读和手势、Android8—15运行测试，也未重新进行手机网络下的更新安装端到端验证。自动标签/布局检查不等于屏幕阅读实际操作。提醒、桌面添加、日签联网来源沿用原实现，其新增行为不在本轮范围。

含课程表或逐门复习的schema6备份需要v1.5.0及以上读取，旧版本不能恢复该新格式；新版本可读旧JSON/ZIP。课表最多100版、每版100条课程，单次调整最多2000条、每天清单最多200项，超限拒绝保存。版本更新仍由“设置 → 关于 → 检查更新”下载并经系统安装确认。
