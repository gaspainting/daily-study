2026年10月18日。versionName 1.4.1 / versionCode 11，基线382569c，修改前工作区干净。沿用Java Activity、APK内HTML/CSS/JS和build.ps1。实现提交dd273da，已同步并发布。

**安排与评估**

| 日型 | 课程复习 | 考研高数 | 总参考 |
|---|---:|---:|---:|
| 工作日，固定课程3门及以上 | 30—50分钟 | 30—70分钟 | 60—120分钟 |
| 工作日，固定课程0—2门 | 20—40分钟 | 40—80分钟 | 60—120分钟 |
| 周六 | 上午60—120分钟 | 下午180—240分钟 | 240—360分钟 |
| 周日 | 上午60—120分钟 | 下午120—180分钟 | 180—300分钟 |

时段灵活分配，周日下午纳入安排。计时休息边界仍为工作日20:30起、周末09:30前和19:00起。

照常按相应计时科目的区间合计；减量使用该区间的50%；仅回顾只比较课程复习分钟与课程复习区间。低于下限未完成，达到下限且不超过上限完成，超过上限超额。休息日不判合格或超额，实际时长保留。单词新学独立比较数量目标，复习数量另记。

只使用正式保存的记录；草稿或保存失败时显示待保存。缺失不转0，部分记录不判整日未学习；未选安排、旧单值、未设目标、计划范围外日期分别显示相应状态。未设目标的0上限科目不参与时长判断。这里衡量参考安排的完成情况，不将学习分钟当作知识掌握程度。详细边界见[安排说明](课程优先安排-v1.4.1.md)。

已有计划在「计划 → 课程与区间安排」预览后点击「应用安排」，更新当天及未来的课程复习、高数参考与新增日期默认值；只改周末可选「周末安排」。确认前呈现覆盖日期、范围和自定参考影响。取消、失败或预览过期不提交。

10月12—15日补展示课程名称及复习顺序。课程未启用的历史日期不增加记录字段或课程分钟，不延长活动期，不改变原实际、参考与统计分母。

**改动文件**

- reference.js、Reference.java：上下限校验、运算、展示、按安排评估及独立新学评估。
- model.js、DataStore.java、tracking.js：schema4联合参考值、旧格式读取、区间周/月合计；原实际统计口径保留。
- schedule.js、CourseSchedule.java、CourseScheduleData.java、course-schedule-data.js：新默认范围、周末独立应用、历史顺序补展示及预览校验。
- docs/source/course-review-policy.json、generate-course-schedule.py：Java/JS共用课程政策与生成表。
- app.js、drafts.js、index.html、polish.css：今日评估、规则入口、上下限编辑、旧草稿恢复、小屏和大字号布局。
- StudyWidget.java、ReportExport.java：区间、真实记录状态与评估；CSV原17列顺序保留、追加3列，PDF包含当日有效区间。
- AndroidManifest.xml、build.ps1、tests：版本、测试专用共享样例及回归；正式包不含仪器入口或测试样例。
- scripts/package-delivery.py、文档：交付包补齐规划文档及其链接的历史报告、课程依据和许可证明，更新使用说明、审查与验证资料。

数据格式为schema4，参考可为旧数字或单一的`{min,max}`，实际记录结构不变。继续读取schema1—3、旧ZIP和JSON；含区间的新备份需要新版App。完整备份容器版本沿用2。草稿、任务和多计划继续独立。相关审查见[CODE-REVIEW-v1.4.1](CODE-REVIEW-v1.4.1.md)。

**文案与出现条件**

| 位置 | 原内容 | 当前内容和条件 |
|---|---|---|
| 今日、计划、统计参考 | 固定分钟，例如90分钟 | 已设置区间时显示60—120分钟；旧单值继续显示原数值 |
| 今日安排评估 | 无 | 保存后显示时长、新学结果及当前安排；规则由“评估规则”入口查看 |
| 时长不完整 | 只有合计与科目记录数 | 评估处显示未记录或待补全时长；0仍是实际0 |
| 编辑或保存失败 | 可能继续看到上一次结论 | 待保存；不把未提交输入显示为新的正式结论 |
| 旧标量参考 | 无评估 | 未设置参考区间，不追溯生成合格结论 |
| 休息记录否值 | 需要调整 | 未保留；底层布尔值与历史记录不变 |
| 周日复习安排 | 早间参考量 | 上午课程、下午高数及合计区间 |
| 计划应用 | 原课程安排入口 | 课程与区间安排/周末安排，预览覆盖范围后应用 |
