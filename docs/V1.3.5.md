# v1.3.5：计划列表布局修复

2026年10月15日，versionName 1.3.5 / versionCode 9。基线为f623a2d，修改前工作区干净。

**问题与修复**

计划列表原先将日期、参考量和记录摘要放在同一条flex行中，摘要使用white-space:nowrap。完成记录后，摘要变长，将中间列压窄。使用已发布的v1.3.4正式APK复现：390px视口中，中间列仅53.5px，科目名称与单位被拆成竖排。

本轮仅为计划列表添加plan-entry作用域，使用固定的日期/箭头位置和可伸展内容列。记录状态、实际分钟、单词数量和记录科目数在参考量下方换行。150%及以上系统字号时，日期、参考量和记录摘要纵向排列。没有缩小字号、裁切或隐藏记录。空白日期的重复“未记录”合并为一处。

相同390px视口中，修复后的中间列为272.2px。既有黑白、细线、字体和整行点击入口保留；参考量、实际值、空值、显式0和统计口径不变。
