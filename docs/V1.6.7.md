构建：v1.6.7 / versionCode 24 / schema 9，2026年10月27日。已发布到[GitHub发行通道](https://github.com/gaspainting/daily-study/releases/tag/v1.6.7)。公开新旧地址、APK摘要及真实v1.6.6客户端启动发现均已核验。

**本轮范围**

以2026年10月26日用户重发的两份方案为依据，来源摘要见[来源记录](requirements-source-v1.6.7.json)。具体自动评估方案的版本实施安排优先于路线图中较早的 v2.1.0 安排；完整自动评估在 v1.6.7 交付。后续整体架构整理和全新视觉仍分别属于 v1.7.0 与 v2.0.0。

**实际实现**

| 模块 | 改动与出现条件 |
|---|---|
| 自动评估引擎 | 新增 evaluation.js 与 Java Evaluation；纯函数按固定依据和正式记录产生分项、整体及活动类型，不读取草稿作为实际值 |
| 时间 | 60—120 分钟中，60/79 为基础、80/90/99 为标准、100/120 为充分、121 为超额；固定值只比较低于、达到和超过；0 下限不独立产生达标日 |
| 词数与数量 | 新学、复习与不同数量分别比较；复习词数有提前目标时参与，单位不同显示需核对，超额不抵消其他目标不足 |
| 必达与参考 | 既有总时长、新学和正数量目标默认必达，时间分项默认参考；课程最低量可在未来日程中设为必达 |
| 提前日程 | 指定日期优先于每周，再优先于默认；回顾独立使用课程时间和复习词数目标，休息日保留实际学习但不增加达标天数 |
| 固定依据 | 按计划时区预存未来每日依据，午夜不依赖 App 运行；当天或过去的降低目标、归档、缩短计划不改变原结论和已结束义务 |
| 修订 | 保存实际修订前后值与时间，执行目标调整有单独记录，调整后结果作为对照；手机日期回退不解冻高水位日期以前的依据 |
| 周月统计 | 主 P/D、覆盖 C/D、次要 P/C；D 为已结束原计划学习及回顾日，当前日不进入；缺失、部分、错误保留在范围内 |
| 计时来源 | 正式日总数仍是唯一实际入口；会话 ID 去重。手动值低于已保存计时时确认修正，保存修正锚点；新计时继续一次累加 |
| 历史与迁移 | 首次成功写入 schema9 时留存旧结果和当前计划；当天过渡，次日完整统计。旧历史继续旧规则，新 JSON/ZIP 保留固定依据和修订 |
| 小组件与报表 | 自动日显示整体结果与记录状态，原计划目标可追溯；CSV 追加整体、复习目标和统计列，原列顺序保留；PDF 区分规则与完整日统计 |
| 课程清单 | putVersion、putChange、saveReviews 不再将当前 schema 降为6，保留 wordLog 字段 |
| 恢复后筛选 | 恢复完成清除引用旧科目的历史与计时筛选，页面可继续打开 |

**文案与交互对照**

| 原内容 | 新内容 | 条件 |
|---|---|---|
| 今日安排：照常 / 减量 / 仅回顾 / 休息 | 直接记录；自动日不提供模式选择 | 自动评估范围内；旧日期仍显示原模式 |
| 按今日安排显示时长完成 | 全部必达目标已完成 / 部分目标完成 / 待补全 | 原目标与正式记录比较后 |
| 当天降低目标后重评 | 执行目标调整；查看原计划与调整后对照 | 当天及以前 |
| 总体分配默认从今天起 | 默认次日起 | 自动评估计划 |
| 按已评估日计算达标率 | 计划达标率与记录完整率 | 完整新规则范围内的已结束日期 |
| 普通日选择休息免评 | 未来明确安排的计划休息 | 提前日程；临时备注保留原计划结果 |
| 保存失败：wordLog 未知字段 | 已保存，或真实错误与重试 | 原生写入完成后才反馈 |
