# 每日学习：阶段规划与状态

当前版本：v1.6.4 / versionCode21。采用用户选择的白底列表界面，今日同页展示科目、集中编辑，设置使用直接入口；保留参考区间、数量、单词分次及历史统计规则。见[V1.6.4](V1.6.4.md)。

任务可添加、编辑、关联科目、勾选、排序、删除和撤销删除。沿用手动保存；草稿与正式状态分开，冲突按ID和字段处理。旧文字保留，各周和各计划独立，新周不自动继承未完成项。

周目标按日期分组。修改开始日期或缩短计划后可从历史回看；手动选择合并或替换另一周，确认后移动。分钟、新学、复习数量继续来自学习记录。
