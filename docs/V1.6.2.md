# 每日学习 v1.6.2

本版修复旧参考区间，并重新组织今日、计划、周复盘和设置。版本来自 Android 构建元数据：1.6.2 / versionCode 19。

**参考区间**

旧实现会将已转换为 `{min,max}` 的固定值跳过；课表改变后的参考匹配还会沿用旧中值。由此产生 30—30、60—60，以及周末沿用工作日/早期周末参考的问题。

本版同时修改 Java 与 JavaScript：按现有课表识别已知内置预设，从设备当天起恢复课程复习与高数的上下限。工作日合计60—120分钟，周六240—360分钟，周日180—300分钟。周末上午课程复习60—120分钟，下午高数周六180—240、周日120—180分钟。自定科目、单词和数量目标不套用这些区间。

当日及未来已保存的评估依据若仍使用相应旧预设，会同步修复时长依据；单词依据保留。历史参考、历史评估和实际记录不批量重算。空白、0、部分记录、减量50%、仅回顾和休息继续使用各自语义。

数据格式升至schema8，新增可选的每日/默认参考手动标记。新编辑的固定值和区间在重新加载、备份恢复、延长计划及新计划模板中保留。经确认应用课程或周末安排时，清除相应日期被替换科目的标记。旧版没有保存目标来源，与内置预设完全相同的旧手动固定值无法区分，按预设修复；重新编辑后会记录手动标记。其他自定区间、非预设固定值和0保留。真正的固定目标在界面、小组件和报表只显示一个数值。

今日切换记录、课程、周目标、评估；记录区一次填写一个科目，所有科目随当天一起保存。安排区可展开，标题显示当前安排。计划切换日程、科目和计划设置；周复盘切换总览、科目统计和本周随记；设置切换提醒、备份与报表、应用。模块切换保留输入，失败保留输入并可重试，错误校验打开对应科目。设计比较、引用与取舍见[设计说明](DESIGN-v1.6.2.md)，文案与条件见[审计](ux-copy-audit.md)。
