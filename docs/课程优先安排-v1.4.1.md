# 课程与区间安排 · v1.4.1

v1.4.1 / versionCode 11，待发布。先复习课程，再进行考研复习；单词按新学、复习数量另记。

**默认参考区间**

| 日型 | 课程复习 | 考研高数 | 合计 |
|---|---:|---:|---:|
| 工作日：当天3门及以上固定课程 | 30—50分钟 | 30—70分钟 | 60—120分钟 |
| 工作日：当天0—2门固定课程 | 20—40分钟 | 40—80分钟 | 60—120分钟 |
| 周六 | 上午60—120分钟 | 下午180—240分钟 | 240—360分钟 |
| 周日 | 上午60—120分钟 | 下午120—180分钟 | 180—300分钟 |

周六上午1—2小时、下午3—4小时；周日上午1—2小时、下午2—3小时。可分段进行，不指定开始钟点。周日下午纳入学习安排。工作日20:30起、周末09:30前和19:00起的计时休息边界保持不变。

**当日评估**

| 今日安排 | 使用的区间 | 计算的实际时长 |
|---|---|---|
| 照常 | 有参考区间的计时科目区间合计 | 对应科目的已保存分钟 |
| 减量 | 照常区间的50% | 同上 |
| 仅回顾 | 课程复习科目的区间 | 只计算课程复习分钟 |
| 休息 | 不分合格或超额 | 显示休息日，保留原实际记录 |

低于下限为“未完成（不合格）”；达到下限且不超过上限为“完成（合格）”；超过上限为“超额完成”。上下限都包含在完成区间内。

例如工作日照常区间60—120分钟：59分钟未完成，60分钟和120分钟完成，121分钟超额。选择减量后按30—60分钟评估。仅回顾按当天课程复习区间评估，高数分钟不计入这项评估。

相关科目时长未填写完整时显示“未记录”或“待补全时长”。明确的0参与判断，空值不替换为0。未选择今日安排时显示“未选择安排”。未设目标、只有旧单值参考、计划范围外的日期不判合格或不合格。上限为0的未设目标科目不参与时长评估。

评估基于保存后的记录；修改表单时显示“待保存”，成功保存后才更新。休息选择只改变评估方式，不清空实际时长。保存了休息安排但未填写分钟时，时长仍为未记录。

单词新学与时长分别评估。低于新学目标为未完成，等于目标为完成，高于目标为超额；复习数量单独展示。新学未填写时不判失败，目标0显示未设置新学目标；休息日不评合格或超额。减量和仅回顾不自动改变新学目标。

这里评估的是所选安排下的时长与新学数量完成情况，不从分钟推断掌握程度，也不生成知识测评分数。

**应用与编辑**

首次加入课程优先安排的原70天计划使用新区间。已有参考量保留，到「计划 → 课程与区间安排」查看日期和覆盖范围，再点击「应用安排」；此入口替换当前计划当天及之后的课程复习、高数参考量，包括自定值，并更新新增日期的默认区间。

仅调整周末时使用「计划 → 周末安排」，只覆盖当天及之后、两科均启用的周末日期。同时更新新增周末日期的默认区间；工作日与过去日期的既有参考值不变。取消、校验失败、保存失败或预览过期时不提交；保存成功后才显示安排已更新。

「修改某一天目标」分别填写上下限；「科目与目标」编辑新增日期的默认上下限。下限不得超过上限。单词继续填写数量目标。

**历史与兼容**

10月12—15日补充复习顺序和当天课程。课程尚未启用的日期只显示课程顺序，不新增课程分钟或输入，不延长启用日期，不重算旧实际记录、参考与统计分母。单双周和开课周次仍依据[原课表](课程优先安排-v1.3.4.md)，本轮不含课表编辑。

学习格式升级为schema4：参考可为旧数字或包含min/max的区间，旧数字保留。支持导入schema1—3及旧ZIP/JSON；旧App不能读取含区间的新备份。各计划独立，周任务、草稿、实际、单词与计时会话保留。

周/月统计、小组件、CSV/PDF显示区间；历史实际合计口径不变。CSV原17列保留顺序，追加当日时长评估、评估区间、新学评估3列；原参考时长列对区间输出“下限—上限”。筛选科目后，当日评估仍使用当天适用的完整科目范围，不改为单科评估。
