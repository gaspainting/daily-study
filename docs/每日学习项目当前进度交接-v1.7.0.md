## 3. 技术栈和数据边界

- Android 原生 Java Activity + WebView。
- 页面使用 HTML、CSS、JavaScript；没有迁移到 Compose、Flutter 或 React Native。
- 数据仍以 JSON 文件保存，包含原子写入、迁移、备份、恢复日志和修订号处理。
- v1.7.0 新增领域入口、版本化桥接契约和存储端口，但没有切换数据库或重写构建系统。
- 正式写入由原生层确认；草稿、输入预览和正式记录分开。
- 应用没有账号、应用级云同步或排行榜。
- 内置 AI 暂不开发，也不是当前版本的隐含依赖。
- 日签图片使用联网来源和本地历史缓存；没有采用离线程序插画方案。
- 用户可见文字遵循直接表达规则：写功能、状态、结果和必要条件，避免内部实现说明和防御性话术。

## 4. 当前已经实现的功能

### 今日记录

- 按日期查看课程复习、考研复习、单词和其他数量科目。
- 时间科目填写实际分钟、内容、题号和问题；支持计时或手动补记。
- 记录今日安排、休息记录和随记；已有字段和历史枚举保持兼容。
- 点击科目进入集中编辑；点击“完成”回到列表，点击“保存记录”提交当天正式记录。
- 保存失败时保留当前输入并提供重试；收到真实写入结果后才显示“已保存”。
- 草稿可在关闭页面或重启后恢复；正式统计和评估不读取未保存草稿。

### 记录状态

- 空白表示未填写，不能静默转换为 0。
- 显式 0 保留为 0 分钟、0 个或 0 单位。
- 只填写部分科目时显示部分记录，不能解释成全天未学习。
- 休息记录保留当天实际填写的学习值，不自动清零。
- 参考目标不会自动写入实际记录。
- 日期、计划或复盘周次切换后，上一份保存反馈不会冒用到新页面。

### 计时和明细

- 时间科目支持开始、暂停、继续、结束和丢弃。
- 计时按净学习时长保存，暂停时间不计入。
- 会话进入计时明细，可按日期和科目筛选。
- 活动计时归属于启动它的计划；切换计划、恢复备份或安装更新前要先处理活动计时。
- 休息边界：工作日 20:30 起；周末 09:30 前和 19:00 起。当前计时受边界影响时显示原因；自动暂停后才显示暂停结果。

### 单词

- 新学和复习分开记录；默认新学目标为每天 50 个，可从“计划 → 总体任务分配”长期修改。
- 支持快捷累加、任意数量添加、修改、移除和撤销。
- 每笔分次记录保存数量、时间和来源；明细修改先进入草稿，保存当天记录后提交。
- 直接编辑总数保留为总数调整；旧记录只有总数时不补造过去的分次明细。
- 统计、评估、小组件、CSV/PDF 和完整备份使用当天正式总数及可用明细。

### 自定义数量科目

- 科目可以选择“时间（分钟）”或“数量”，数量单位可写题、页、组等。
- 数量目标按周一至周日设置，也可以按日期单独修改。
- 数量科目不进入分钟合计，也不显示计时入口。
- 历史记录保留当时单位；修改单位不会重解释旧记录。
- 统计和报表按单位分别汇总，单位不同不会强行相加。

### 课程表和课程复习

- 课程可编辑名称、星期、节次、教学周、单双周和起止日期。
- 支持单次调课、停课、撤销调整和调整历史。
- 今日显示当天课程，周末可查看本周课程汇总。
- 每门课程有独立复习清单和复习笔记，可关联周任务。
- 课程名称、节次、原日期和关联任务会保存快照，后续改名或归档后仍可回看。
- 课程清单、学习分钟、单词数量和周任务分别保存，不互相推断完成。

### 每周目标和任务

- 每周目标由用户自行填写，旧的固定教材周目标已经移除。
- 支持整体目标、随记和任务清单。
- 任务支持添加、编辑、排序、勾选、关联科目、删除和撤销删除。
- 今日页可以勾选本周任务；周复盘列出已完成和未完成任务。
- 新周不自动复制上一周未完成任务。

### 总体任务分配

入口：**计划 → 总体任务分配**。

- 一次修改未来每日新学单词目标。
- 一次修改未来参考时间总区间、各科分项和其他数量目标。
- 支持生效日期、工作日批量填写、保留或覆盖单日目标。
- 应用前显示日期范围、修改项、保留项和是否影响已有评估。
- 生效日前的目标、历史实际记录、词数、随记和计时明细保留。

### 自动评估

v1.6.7 已交付自动评估，v1.6.8 修复历史补录入口，v1.7.0 只整理接口和桥接，不改变评估口径。

- 系统按当天开始前确定的计划、目标和正式记录自动评估。
- 不再依靠用户每天选择“照常、减量、仅回顾、休息”来改变普通日目标。
- 普通日时间低于下限为未完成，区间内为完成，高于上限为超额；单词和数量分开评估。
- 计划回顾日使用课程复习目标；计划休息日显示休息日并保留实际记录。
- 目标依据按日期留存，包含时间区间、单词目标、数量目标、单位和来源。
- 当天或未来目标调整可查看原计划与调整后对照；历史结果不会被静默改写。
- 周/月复盘同时显示计划达标率和记录完整率。
- 空白、0、部分记录、单位错误、临时休息和计划休息分别处理。

### 复盘、历史和统计

- 周复盘：总览、科目统计、本周随记、周任务和每日评估。
- 月历和月统计：时长、单词、数量、记录状态和趋势。
- 历史：日期、科目、关键词、安排、记录状态和评估结果筛选。
- 可查找计划内尚未记录日期，也可查看计划范围外已有历史记录。
- 计时明细独立按日期和科目筛选。
- 不同数量单位分别统计；分钟、单词和数量不混合。

### 日签和启动图文

- 每次重新启动时显示一组随机图文，默认约 5 秒，可跳过；后台返回不重复播放。
- 日签每天抽取一次，当天固定，可反复查看。
- 支持日签历史、收藏、开屏回看、关键词/主题/语言筛选。
- 支持保存图片和系统分享；长文字保留可读排版、日期、中文释义和真实署名。
- 图片通过联网来源获取并校验，历史图文和图片可在本地回看。
- 作者、图片来源、许可和排版归属按实际数据显示，不使用“原创”作为通用来源说明。

### 提醒、小组件、备份和报表

- 提醒默认关闭；用户主动开启时请求通知权限。
- 设置页显示真实权限状态；权限拒绝时提供系统设置入口。
- 小组件支持查看当天摘要；发起添加不等于添加成功，成功需以系统回调为准。
- 完整 ZIP 备份包含计划、记录、草稿相关必要数据、日签历史和实际图片。
- 兼容旧 JSON 和旧 ZIP；恢复前校验内容、处理活动计时并确认实际覆盖范围。
- 支持 CSV/PDF 报表；报表按分钟、单词和数量单位分别输出。

### App 内更新

- 从 v1.5.2 起冷启动自动检查更新；v1.6.6 起后台返回按间隔静默补查。
- 发现新版时启动页或页头显示更新入口；下载可取消、重试并显示进度。
- 安装前处理未保存输入和活动计时，安装结果以系统和重新启动后的真实版本为准。
- 更新清单来自 GitHub，正式 APK 使用同包名和同签名覆盖安装。

## 5. v1.7.0 已完成的架构工作

- `domain-contract.js`：页面正式使用领域入口进行状态迁移、校验、记录和规则调用。

- `StudyStorage.java`：为稳定读取、UI读取、状态保存和评估日程保存提供存储端口。
- `MainActivity.java`：正式页面保存接入版本化桥接；旧入口暂留给兼容测试和旧调用路径。
- `tests/fixtures/rule-contract-cases.json`：Java 与 JavaScript 共用规则样例。
- `tests/bridge-contract.test.cjs`、`tests/domain-contract.test.cjs`、`tests/bridge-contract-ui.cjs`：契约、领域和真实 WebView 回归。

本版没有迁移 schema、数据库、UI 框架或自动评估规则。
