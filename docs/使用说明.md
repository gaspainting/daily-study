# 每日学习 v1.5.3 使用说明

版本：v1.5.3 / versionCode 16，2026年10月21日发布。

**安装与更新**

安装包为「每日学习-v1.5.3.apk」，可从原版「设置 → 关于 → 检查更新」或[GitHub发行页](https://github.com/gaspainting/daily-study/releases/tag/v1.5.3)下载。安装本版后，重新启动App会自动检查新版，发现后显示下载入口；选择“稍后”后可从页头继续更新。后台返回不再弹出，离线时正常使用。覆盖安装保留应用数据；卸载会删除应用数据。最低 Android 8.0，目标设备 vivo X100s / Android 16。「关于」显示实际安装版本。

下载完成后点击安装，按 Android 提示授权并确认。从安装权限设置返回后，再点击安装。取消后可继续使用原版本。当前有计时时先结束并保存，或确认丢弃。手机网络需要能访问 GitHub。

**App内使用手册**

在「设置」页点击「使用手册」，选择目录中的章节阅读。章节可展开或收起；阅读时点击顶部「目录」返回目录，点击关闭或使用系统返回键退出。手册随安装包提供，可离线阅读。

**计划与科目**

点击页面上方的计划名称打开计划列表，可切换已有计划或新建计划，最多 8 个。新计划设置名称、开始和结束日期，以当前科目及参考模板建立，学习记录、复盘和计时明细从空白开始。各计划的记录、草稿、统计和学习提醒分别保留；日签共用。

活动计时属于启动时的计划。保存或丢弃后才可切换；暂停中的计时也需先处理。桌面小组件显示当前计划。

「计划」可编辑日期、每日目标、周目标和科目。「科目与目标」中可以上移、下移、归档或恢复科目。归档从当天生效，历史记录仍可查看和修改。新增科目从当天起纳入参考与记录统计；已归档科目有记录的日期仍显示该记录。

**课程复习与考研安排**

今日页“复习顺序”先列课程复习，再列高数。工作日总参考60—120分钟；周六上午课程复习60—120分钟、下午高数180—240分钟；周日上午课程复习60—120分钟、下午高数120—180分钟。每天灵活分段，周日下午纳入安排，见[课程与区间安排及评估规则](课程优先安排-v1.4.1.md)。

当天及以后日期按现有课表与计划自动补齐参考区间。今日页总区间旁的「修改」、复习顺序和科目记录旁的区间均可打开编辑；总区间与分项联动，单词目标单独设置。

「计划 → 课程与区间安排」可预览并应用另一套安排；只调整周末可选「周末安排」。确认前显示实际日期和覆盖范围，参考自定值也会替换。过去日期、实际记录与词数保留。每日上下限与科目默认上下限可分别编辑。

**今日评估**

照常按总参考区间，减量按其50%，仅回顾只计算课程复习并使用课程复习区间。低于下限为未完成（不合格），区间内含上下限为完成（合格），超过上限为超额完成。休息日不判不合格或超额，保留真实时长。

评估使用已保存记录；编辑中显示待保存，时长未记齐时待补全，空白和0分别处理。旧版单值按相同上下限评估。单词新学与时长分别评估：低于目标、达到目标、超过目标分别对应未完成、完成、超额；复习另记，休息日不评级。

今日评估的「评估依据」可查看参考来源、留存时间、当日安排和实际值。新增记录保存时留存依据；旧记录未留存时显示当前参考，升级后首次保存时留存此前可取得的参考。修改当天目标并保存后默认按新目标评估；需要原结论时选择「保留原依据」。单独重评仍可先预览再确认。编辑实际或安排仍需保存。

周/月复盘分别统计时长、新学达标率，分母只包括已评估日期，休息、未记录和待补全另列。点击汇总可打开对应历史筛选；历史也可独立选择评估项目与结果。「未记录」可查找计划内尚未保存的日期。周复盘有每日结果，月历有每周达标趋势。

**记录、草稿与计时**

今日页分别显示时长与单词数量。高数等计时科目记录分钟；单词填写「新学（个）」「复习（个）」。新学目标默认每天50个，复习数量单独统计。空白为「未记录」，填写0则保留0。选择休息保留原有数值。

填写后点击「保存这一天」。保存失败时输入保留，可点击「重试」。计划编辑和复盘分别保存。输入会另存为草稿，退出或重启后可恢复；统计和报表只使用正式记录。草稿按计划、日期、周或表单区分，可清除单份，或在设置清除全部草稿。正式记录已发生冲突时，可选择使用草稿或保留当前记录。

计时科目可暂停、继续、结束并保存，或确认丢弃。暂停时长不计入净学习时间。工作日 20:30 起、周末 09:30 前和 19:00 起自动暂停。边界在「设置 → 休息时段」查看。历史日期使用手动补记。

**单词与每周目标**

单词页分别提供新学、复习的快捷累加按钮，默认 +5、+10、+20；「计划 → 科目与目标」可设置三个加数。点击「撤销」恢复当前字段最近一次累加前的值；直接修改、成功保存或切换日期后重新开始撤销上下文。可在碎片时间分次填写，也可直接输入当天数量。完成输入后点击「保存这一天」。草稿会恢复输入，正式统计使用保存后的数值。

「计划 → 科目与目标」修改每日新学目标，对今天及之后的计划日期生效；过去日期的目标保留。「修改某一天目标」可单独设置一天的新学数量。旧单词时长在有记录的日期以「时长记录」折叠展示，计时明细保留。

在今日、计划或周复盘点击「编辑本周目标」。填写整体目标及随记，也可添加任务，关联科目、排序、勾选或删除；删除后可撤销。每周最多50项，每项名称最多500字，原有文字目标保留。

今日勾选后点击「保存目标」。未保存内容作为草稿恢复，周复盘展示正式保存的完成项与未完成项。任务完成数、学习分钟和词数分别统计。各计划、各周独立，新周任务从空白开始。

「历史目标」可查看、修改过往目标。调整计划日期后，目标保留原日期分组。目标编辑页选择「移到另一周」，可合并或替换；确认框显示实际范围，取消不移动。相关周有草稿时先处理草稿。

**课程表与逐门复习**

「计划 → 课程表」按日期查看课程。进入「编辑课表」可修改课程名称、星期、节次、起止教学周和单双周，并设置“教学周对应的周一”及周数。保存时选择今天及之后的生效日期；先前课表保留在版本记录中。已有未来课表时编辑最新版本，生效日不能早于该版本。

「临时调课 / 停课」选择原日期和课程，调到另一天或停课。尚未发生的调整可以确认撤销，已发生的调整留在调课记录中。课程表编辑和调课不会自行替换学习参考区间；需要时使用「按课表调整」预览并确认。

今日「逐门复习」列出当天课程。周末列出本周截至当天的课程，同名课程合并显示。可勾选、填写复习笔记、关联本周任务，再点「保存复习清单」。清单的勾选与学习分钟、单词数量、周任务完成状态分别保存。查看旧日期可回看或修改已保存的清单。

复习记录保留当时的课程名称、节次、来源日期与所关联任务的名称；改课表、改任务名称或移除任务后仍可回看。课表和清单的未保存输入可作为草稿恢复。各计划独立，新计划从空课表开始。

**复盘、月历与历史**

「复盘」顶部切换周复盘、月历、历史和计时明细。周复盘按当前及历史有记录的科目提供回顾字段，保留旧高数、单词复盘。

「半天休息记录（选填）」按实际情况选择未记录、已保留或未保留。

月历显示每天的已记录时长、单词新学与复习数量、科目记录数及随记。周/月统计将词数和分钟分开显示。点击日期打开当日记录。历史可按日期、科目、随记和内容关键词、今日安排、记录状态筛选，包含计划日期之外的既有记录。计时明细按日期、科目筛选，显示净时长和结束时间。

**学习报表与备份**

「设置 → 导出学习报表」可选择日期范围、科目和 CSV/PDF 格式；周复盘、月历也提供导出入口。报表包括计划名称、参考与实际、记录内容、随记及计时合计。PDF另收录日期范围内的整体目标、随记和任务状态；科目筛选时保留未关联科目及所选科目的任务。CSV参考列显示上下限，保留评估结果与依据列，并追加“逐门课程复习”列，可用表格软件打开，PDF可阅读或打印。报表不能用来恢复应用数据。

「导出备份」在系统文件选择器指定位置。成功完成后更新上次备份日期。「备份提醒」可选择 7、14 或 30 天间隔，开启并保存后生效。未授权时从通知设置入口处理。

「从备份恢复」兼容新旧 ZIP、旧 JSON。新版完整 ZIP 包含课表、课程复习清单和周任务，替换全部计划及日签；旧 ZIP 替换当前计划及日签；旧 JSON 只替换当前计划。确认框显示实际覆盖范围和计划数，取消不覆盖。含课表或课程复习清单的备份需要v1.5.0及以上版本。当前计时先保存或确认丢弃。恢复成功会清除对应范围的未保存草稿。

**日签**

重新启动时随机展示图文 5 秒，可跳过；后台返回直接进入原页面。每天可抽一次日签，当天固定。支持收藏、历史回看、保存图片及系统分享。文字与图片分别署名，外文附中文释义。

在历史、收藏、开屏历史中可按关键词、主题和语言筛选；关键词也检索中文释义与作者等已有来源字段。筛选不重新抽取当天日签。图片沿用联网来源。

**提醒与桌面**

主动开启学习提醒后处理系统通知权限，并保存时间。关闭时取消开关再保存。「未收到提醒？」提供系统调度帮助。学习提醒和备份提醒遵守既有休息边界。

「添加到桌面」发起系统请求，在桌面确认后完成添加；添加帮助提供手动方式。
