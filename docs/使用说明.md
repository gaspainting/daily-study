# 每日学习 v1.6.7 使用说明

版本：v1.6.7 / versionCode 24，2026年10月27日。

**页面导航**

今日页在概览下切换「记录、课程、本周、评估」。记录区同时列出各科实际值和参考值，点击科目打开编辑，在编辑弹层或今日页底部点击「保存记录」提交；「完成」仅返回列表。单词列表的「记一笔」可直接添加分次记录。「休息记录」与「随记」有各自入口，旧规则日期保留原安排。周复盘分为「总览、科目统计、本周随记」。设置使用「学习、数据、应用」分组列表，提醒、备份、小组件、使用手册和关于直接可见。

**安装与更新**

安装包为「每日学习-v1.6.7.apk」，可从原版更新入口或[GitHub发行页](https://github.com/gaspainting/daily-study/releases/tag/v1.6.7)下载。重新启动App会自动检查新版，发现后显示下载入口；选择“稍后”后可从页头继续更新。后台返回按至少5分钟间隔补查，发现新版时显示页头入口。覆盖安装保留应用数据；卸载会删除应用数据。最低 Android 8.0，目标设备 vivo X100s / Android 16。「关于」显示实际安装版本。

下载完成后点击安装，按 Android 提示授权并确认。从安装权限设置返回后，再点击安装。取消后可继续使用原版本。当前有计时时先结束并保存，或确认丢弃。手机网络需要能访问 GitHub。

**App内使用手册**

在「设置」页点击「使用手册」，选择目录中的章节阅读。章节可展开或收起；阅读时点击顶部「目录」返回目录，点击关闭或使用系统返回键退出。手册随安装包提供，可离线阅读。

**总体任务分配**

进入「计划 → 总体任务分配」，选择生效日期，集中修改每日新学、周一至周日总参考区间及科目分项、数量目标。总区间与分项联动，可把当前星期的时间分配复制到周一至周五。选择保留或覆盖单日自定目标，确认日期和修改数量后应用，自动评估计划默认从次日起生效。生效日前的目标和实际记录保留，之后新增日期沿用修改后的默认分配。各计划分别修改。

**计划与科目**

点击页面上方的计划名称打开计划列表，可切换已有计划或新建计划，最多 8 个。新计划设置名称、开始和结束日期，以当前科目及参考模板建立，学习记录、复盘和计时明细从空白开始。各计划的记录、草稿、统计和学习提醒分别保留；日签共用。

活动计时属于启动时的计划。保存或丢弃后才可切换；暂停中的计时也需先处理。桌面小组件显示当前计划。

「计划」分为本周安排、科目和计划设置。本周安排查看每日总参考、课程摘要与课程表，科目管理目标和排序，计划设置调整日期与参考安排。「科目」中可以上移、下移、归档或恢复科目。归档从当天生效，历史记录仍可查看和修改。新增科目可选择分钟或数量，数量科目填写单位与每日目标。科目从当天起纳入参考与记录统计；已归档科目有记录的日期仍显示该记录。

**课程复习与考研安排**

今日页“复习顺序”先列课程复习，再列高数。工作日总参考60—120分钟；周六上午课程复习60—120分钟、下午高数180—240分钟；周日上午课程复习60—120分钟、下午高数120—180分钟。每天灵活分段，周日下午纳入安排，见[课程与区间安排及评估规则](课程优先安排-v1.4.1.md)。

当天及以后日期按现有课表与计划自动补齐参考区间。点击今日页总参考区间、复习顺序中的区间，或科目编辑内的参考值均可修改；总区间与分项联动，单词目标单独设置。

「计划 → 计划设置 → 课程与区间安排」可预览并应用另一套安排；只调整周末可选「周末安排」。确认前显示实际日期和覆盖范围，参考自定值也会替换。过去日期、实际记录与词数保留。每日上下限与科目默认上下限可分别编辑。

**今日评估**

保存后按原计划分别核对总时长、单词和数量；全部必达项达到最低要求才记为达标日。总时长默认必达，时间分项默认参考；新学与复习分开，数量按自己的单位计算。

时间区间内部三等分，依次显示基础、标准、充分达标。例如60—120分钟时，60/79为基础、80/90/99为标准、100/120为充分，超过120为时长超额。固定目标只比较低于、达到和超过。空白保持未记录，0是明确记录，部分必达输入为空时显示待补全。

在「计划 → 评估日程」设置默认、每周或指定日期安排，指定日期优先于每周，每周优先于默认。日程从未来日期生效。计划回顾使用独立的课程回顾时间和复习词数目标；计划休息不设置必达任务，实际学习照常保留。

当天开始前按计划时区固定目标与单位。「今日 → 评估 → 查看依据」可查看原目标、来源、实际修订和目标调整后对照；当天降低执行目标不会替换主评价。统一分配、单词默认量与数量单位调整默认从次日起影响未来。

主计划达标率为全部达标日P / 已结束计划日D，同时显示记录完整率C / D。未记录、待补全、临时中断和需核对的原计划日保留在分母，今天显示进行中。已完整记录日达标率P / C为次要分析。有效计划休息不进入D，也不增加P。

首次升级当天为过渡日，整日统计从次日00:00起。此前日期保留旧规则与已有依据，过渡日已有旧结果可在依据中查看。补记仍按对应日期的原依据计算。

手动时长少于已保存计时明细时，保存前核对并确认修正；正式总数仍是统计入口，同一会话只计一次。完整实现与验证见[V1.6.7](V1.6.7.md)。

**记录、草稿与计时**

今日页分别显示时长与单词数量。高数等计时科目记录分钟；单词填写「新学（个）」「复习（个）」。新学目标默认每天50个，复习数量单独统计。空白为「未记录」，填写0则保留0。选择休息保留原有数值。

填写后点击「保存记录」。保存失败时输入保留，可点击「重试」。计划编辑和复盘分别保存。输入会另存为草稿，退出或重启后可恢复；统计和报表只使用正式记录。草稿按计划、日期、周或表单区分，可清除单份，或在设置清除全部草稿。正式记录已发生冲突时，可选择使用草稿或保留当前记录。

计时科目可暂停、继续、结束并保存，或确认丢弃。暂停时长不计入净学习时间。工作日 20:30 起、周末 09:30 前和 19:00 起自动暂停。边界在「设置 → 休息时段」查看。历史日期使用手动补记。

**单词与每周目标**

单词页分别提供新学、复习的快捷累加按钮，默认 +5、+10、+20；「计划 → 科目」可设置三个加数。点击「撤销」恢复当前字段最近一次累加前的值；直接修改、成功保存或切换日期后重新开始撤销上下文。使用「记一笔」可输入其他数量。每次累加保留数量、记录时间和来源，可在「分次记录」修改或移除；移除后有「撤销移除」。修改时预览当天新学和复习总数。直接编辑每日数量会记为「总数调整」。所有改动先保留为草稿，点击「保存记录」后提交；统计与评估使用已保存的总数。原有记录保留总数，新添加的分次明细从本版开始记录。

「计划 → 科目」修改每日新学目标，对今天及之后的计划日期生效；过去日期的目标保留。「修改某一天目标」可单独设置一天的新学数量。旧单词时长在有记录的日期以「时长记录」折叠展示，计时明细保留。

在今日、计划或周复盘点击「编辑本周目标」。填写整体目标及随记，也可添加任务，关联科目、排序、勾选或删除；删除后可撤销。每周最多50项，每项名称最多500字，原有文字目标保留。

今日勾选后点击「保存目标」。未保存内容作为草稿恢复，周复盘展示正式保存的完成项与未完成项。任务完成数、学习分钟和词数分别统计。各计划、各周独立，新周任务从空白开始。

「历史目标」可查看、修改过往目标。调整计划日期后，目标保留原日期分组。目标编辑页选择「移到另一周」，可合并或替换；确认框显示实际范围，取消不移动。相关周有草稿时先处理草稿。

**课程表与逐门复习**

「计划 → 课程表」按日期查看课程。进入「编辑课表」可修改课程名称、星期、节次、起止教学周和单双周，并设置“教学周对应的周一”及周数。保存时选择今天及之后的生效日期；先前课表保留在版本记录中。已有未来课表时编辑最新版本，生效日不能早于该版本。

「临时调课 / 停课」选择原日期和课程，调到另一天或停课。尚未发生的调整可以确认撤销，已发生的调整留在调课记录中。课程表编辑和调课不会自行替换学习参考区间；需要时使用「按课表调整」预览并确认。

今日「逐门复习」列出当天课程。周末列出本周截至当天的课程，同名课程合并显示。可勾选、填写复习笔记、关联本周任务，再点「保存复习清单」。清单的勾选与学习分钟、单词数量、周任务完成状态分别保存。查看旧日期可回看或修改已保存的清单。

复习记录保留当时的课程名称、节次、来源日期与所关联任务的名称；改课表、改任务名称或移除任务后仍可回看。课表和清单的未保存输入可作为草稿恢复。各计划独立，新计划从空课表开始。

**复盘、月历与历史**

「复盘」顶部切换周复盘、月历、历史和计时明细。周复盘按当前及历史有记录的科目提供回顾字段，保留旧高数、单词复盘。

「半天休息记录（选填）」按实际情况选择未记录、已保留或未保留。

月历显示每天的已记录时长、单词新学与复习数量、科目记录数及随记。周/月统计将词数和分钟分开显示。点击日期打开当日记录。历史可按日期、科目、随记和内容关键词、今日安排、记录状态筛选，包含计划日期之外的既有记录。计时明细按日期、科目筛选，显示净时长和结束时间。

**学习报表与备份**

「设置 → 备份与导出 → 导出学习报表」可选择日期范围、科目和 CSV/PDF 格式；周复盘、月历也提供导出入口。报表包括计划名称、参考与实际、记录内容、随记及计时合计。PDF另收录日期范围内的整体目标、随记和任务状态；科目筛选时保留未关联科目及所选科目的任务。CSV参考列显示上下限，保留评估结果与依据列，并追加“逐门课程复习”列，可用表格软件打开，PDF可阅读或打印。报表不能用来恢复应用数据。

「导出备份」在系统文件选择器指定位置。成功完成后更新上次备份日期。「备份提醒」可选择 7、14 或 30 天间隔，开启并保存后生效。未授权时从通知设置入口处理。

「从备份恢复」兼容新旧 ZIP、旧 JSON。新版完整 ZIP 包含课表、课程复习清单和周任务，替换全部计划及日签；旧 ZIP 替换当前计划及日签；旧 JSON 只替换当前计划。确认框显示实际覆盖范围和计划数，取消不覆盖。含课表或课程复习清单的备份需要v1.5.0及以上版本。当前计时先保存或确认丢弃。恢复成功会清除对应范围的未保存草稿。

**日签**

重新启动时随机展示图文 5 秒，可跳过；后台返回直接进入原页面。每天可抽一次日签，当天固定。支持收藏、历史回看、保存图片及系统分享。文字与图片分别署名，外文附中文释义。

在历史、收藏、开屏历史中可按关键词、主题和语言筛选；关键词也检索中文释义与作者等已有来源字段。筛选不重新抽取当天日签。图片沿用联网来源。

**提醒与桌面**

主动开启学习提醒后处理系统通知权限，并保存时间。关闭时取消开关再保存。「未收到提醒？」提供系统调度帮助。学习提醒和备份提醒遵守既有休息边界。

「添加到桌面」发起系统请求，在桌面确认后完成添加；添加帮助提供手动方式。

本轮功能与验证见[V1.5.3](V1.5.3.md)，课程安排见[v1.4.1安排说明](课程优先安排-v1.4.1.md)，文案对照见[文案审计](ux-copy-audit.md)。历次发行的测试结果与验证范围保留在对应版本报告中。

**数量单位与统计**

在「计划 → 科目」修改数量单位，今天起未记录的日期使用新单位。历史记录、已有记录的日期及对应目标保留原单位，修改旧数量时也使用该记录的单位。周/月统计按单位分别展示，不把题数与组数相加。

历史筛选选择数量科目后，记录状态和数量评估按该科目判断；关键词支持数量和单位，例如「3 组」。数量草稿带有单位；单位变化时，可选择使用草稿或保留当前表单。实际与评估目标单位不同会显示「单位不同」。

CSV/PDF按单位汇总，分别列出数量评估和评估目标单位。旧JSON及ZIP仍可恢复。完整修改与验证见[V1.6.3](V1.6.3.md)。
