# 每日学习 v1.6.4

版本：v1.6.4 / versionCode21。数据 schema8。设计依据见 [白底列表界面](DESIGN-v1.6.4.md)。

**已实现**

- 今日同页列出各科名称、参考值与实际值，使用白底、细线和蓝色操作。
- 科目、今日安排及随记使用集中编辑；“完成”返回列表，底部“保存记录”提交全部科目。
- 输入预览与保存状态分开。空值、0、部分记录、无效输入和正式保存继续分别处理；正式评估仍使用已保存记录。
- 参考目标或后台刷新引起重绘时恢复正在编辑的科目及滚动位置。系统返回先关闭编辑器。
- 设置使用学习、数据、应用分组，提醒、休息时段、备份、小组件、手册和关于直接可见。
- 计划突出每日总参考与课程摘要，复盘、日签、图表和弹层统一排版。作者与来源保留。
- 启动更新检查的迟到结果避开正在使用的科目或设置编辑器，页头仍保留更新入口。

**文案与条件**

| 原界面 | 本版 | 条件 |
| --- | --- | --- |
| 科目切换按钮及整块表单 | 科目列表 → 集中编辑 | 点科目打开，原字段保留 |
| 保存这一天 | 保存记录 | 点击后校验，通过原生保存才反馈成功 |
| 已记录时长 | 填写时长、待保存 | 有未保存修改时；正式记录与评估不提前改写 |
| 周目标 | 本周 | 今日模块入口 |
| 提醒 / 备份与报表 / 应用分页 | 六个分组列表入口 | 正常设置首页；具体表单按需打开 |

保存失败的重试、权限异常、当前计时限制、恢复覆盖范围和必要署名继续在对应场景显示。

**主要修改**

- `layout.js` / `layout.css`：列表、集中编辑、分组设置、字体层级、短屏与大字号布局。
- `app.js` / `index.html`：实际与参考的顺序、页头计划切换、计时入口及原页面生命周期衔接。
- `manual.js`：操作路径与按钮名称同步。
- 原生窗口背景及系统强调色：白底与蓝色；版本从构建元数据读取。
- `tests`：导航、真实表单归属、编辑器、嵌套目标编辑、保存与草稿、返回、布局与更新衔接。

参考生成、时长与数量评估、学习统计、备份兼容和休息边界算法沿用现有实现。
