# v1.4.1 相关代码审查

基线382569c（v1.4.0交付），本轮在现有Java/WebView架构中加入参考区间与按安排评估，未新增服务、权限或账号。

**数据与计算**

- schema4的参考值为旧数字或`{min,max}`，保留单一来源。JS/Java均校验字段、有限数值、0—1440范围与下限不超过上限。实际分钟与词数结构不变，schema1—3继续读取。
- `reference.js`与`Reference.java`按保存后的状态计算。照常合计参考区间，减量按50%，仅回顾仅计课程复习，休息单独标记；单词新学另评。上限为0的未设目标科目不参与时长评估。
- 缺失分钟不转0，相关时长未齐不判失败或超额；未选安排、旧单值、未启用课程复习、计划外日期分别保留真实状态。比较包含上下限，使用1e-9的浮点误差容限；原计时与合计精度不改。
- 两端共用24项手写预期样例，覆盖阈值前后、0加未知、仅回顾忽略高数、休息保留实际、新学与复习独立。评估不写回记录、任务或参考。
- `M.target`保留旧算法需要的数值接口，区间以独立展示接口输出；周/月统计附带区间合计，所有本轮涉及的展示使用上下限。旧标量统计输出与算法基准继续比较。

**安排与历史**

- 默认表由policy生成Java/JS同一70天数据。工作日60—120、周六240—360、周日180—300分钟。上午、下午范围按已应用的参考显示。
- 既有安排经预览确认再更新。周末操作只调整符合活动期的当天及未来周末；全量操作调整预览内日期，同时更新新增日期的默认区间。变更默认值前固定过去缺省参考的原值，实际记录与历史统计分母不变。
- 预览绑定计划、日期范围和保存版本，发生并发修改时要求重新预览。取消、校验或写入失败不关闭为成功，真实持久化后才确认。
- 10月12—15日仅补展示。只对原计划、原课表内、课程首次启用之前的日期使用；不复活归档间隙或空活动期，不增加历史科目或分钟。

**表单与输出**

- 单日目标和科目默认值均编辑上下限；新上限控件使用冒号分隔，避免与可导入的`math-max`等科目ID冲突。旧单值草稿扩为显式点区间，沿用冲突选择，不静默丢弃待保存输入。
- 正在编辑或保存失败时显示待保存，隐藏旧的评估结果；恢复草稿后仍需手动保存。评估明细标出当前安排及其有效区间，避免把减量区间与计划基准混淆。
- 小组件保留计数、0与未知值，另呈现区间和正式评估。休息日只显示一次。
- CSV旧17列顺序保留，参考列可含区间，追加3个评估列；PDF按日期显示当日时长评估及适用区间。科目筛选不改变当天评估范围。
- 交付资料包沿文档本地链接收录历史报告、课程依据和许可证明，保持相对路径；限制在公开docs目录中，独立校验链接和文件摘要。

**测试脚本修正**

初版新增回归脚本通过Windows ADB stdin恢复原始二进制，图片在控制字节处被截断。受影响仅为模拟器6张缓存图片；已从既有完整备份恢复，6张图片与其余原始文件合计9项SHA256全部匹配，真实手机未参与。

脚本现先将完整快照与清单保存到本机临时目录，再经ASCII Base64传输恢复，逐文件核对摘要、模式和文件清单；正式包验证使用模拟器root并恢复原属主。快照枚举错误中止测试，拒绝符号链接与特殊文件。测试快照和恢复内容不上传GitHub。

执行结果、页面与剩余验证范围见[V1.4.1](V1.4.1.md)。
