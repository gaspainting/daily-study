# v1.4.2 开发与验证

2026年10月19日。versionName 1.4.2 / versionCode 12，基线f4de055，修改前工作区干净。当前完成实现，正在验证发布。

**本轮功能**

| 功能 | 入口和行为 |
|---|---|
| 历史评估筛选 | 复盘 → 历史，分别选择时长/单词新学、完成/超额/未完成/休息/未记录/待补全/待评估；可叠加原筛选 |
| 评估依据 | 今日 → 评估依据，查看参考来源、留存时间、各科目标、安排、实际与有效区间 |
| 历史目标调整 | 修改某一天目标，默认保留原依据，可选择按新目标重评；依据页也可预览重评并确认 |
| 周/月评估 | 时长和新学分别统计达标率；休息、空白和待补全另计；点击可回看相应记录 |
| 趋势 | 周复盘查看每日结果，月历查看分周达标趋势 |
| 报表 | CSV/PDF带上留存来源、时间和评估新学目标 |

照常、减量50%、仅回顾课程复习、休息日及单词独立评估规则保持。课程安排沿用[v1.4.1](课程优先安排-v1.4.1.md)，本轮没有重新分配参考时间。用户填写的实际、周任务、随记与历史统计口径保留。

**数据与关键决策**

学习格式为schema5，新增日期级评估依据。旧schema1—4、旧ZIP/JSON继续读取；读取本身不写回文件，旧数据未留存时使用当前参考并明确标记。升级后首次保存会留存操作前已有记录的参考，标记“首次留存参考”；新增记录使用“保存时参考”，主动重评使用“重评时参考”。旧记录更早的参考变化不能从现有文件还原。

实际值继续保存在原记录中。编辑实际或安排后，以留存的科目、参考与目标重新计算。重评仅替换依据；取消不写，失败可重试，预览过期需重新预览，跨计划确认被拒绝。

达标率为（完成天数＋超额天数）/已评估天数；已评估仅含完成、超额和未完成。分母0不显示百分比。未来未记录日期不计入当前统计；明确保存过的未来记录仍保留。未记录筛选可显示计划内尚无记录的日期，不补写空记录。

- StudyWidget.java：当前参考与留存时长依据不同时，用“按原区间”标明评估来源，保留原有布局和记录计数。
- AndroidManifest.xml：1.4.2/code12。权限和签名沿用。
- tests：新增模型、原生、备份及WebView场景；复用具备完整快照恢复的模拟器包装脚本，更新迁移断言。

详细检查见[相关代码审查](CODE-REVIEW-v1.4.2.md)。

**文案与条件**

| 场景 | 当前文案/状态 |
|---|---|
| 没有留存依据 | 当前参考（未留存） |
| 旧记录首次留存 | 首次留存参考及真实留存时间 |
| 新记录保存 | 保存时参考 |
| 用户确认重评 | 重评时参考；写入成功后显示已重新评估 |
| 更改历史目标 | 保留原依据 / 按新目标重评 |
| 重评确认前 | 明确将替换这一天的评估依据，学习记录不变 |
| 并发变化 | 记录已更新，请重新预览；按钮切换为重新预览 |
| 表单未保存 | 先保存当天记录；输入保持在表单中 |
| 汇总 | 达标X / 已评估Y天，另列休息、未记录、待补全、待评估 |
