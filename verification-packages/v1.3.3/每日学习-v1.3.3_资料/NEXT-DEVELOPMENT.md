**后续候选**

- 通用计量方式：新增科目可选择分钟或数量，数量单位可填「题」「页」「个」等。当前新增科目为按分钟记录，此项需要同步扩展记录、目标、统计、小组件、备份与报表，适合单独一轮开发；默认科目继续保持高数和单词。
- 单词分次记录明细：显示各次增量、时间及新学/复习类别。当前只保存每日总数与草稿，明细应与手动保存、修改和撤销保持一致，避免将输入事件当成正式记录。

各阶段继续采用字段标签、真实状态和操作反馈，保持现有黑白、细线与留白。验收包含空白与0、部分记录、多计划隔离、旧备份、保存失败、覆盖前确认和必要署名。App 内置 AI 继续暂缓。
