**记录和恢复语义**

草稿与正式记录分开，按计划/日期/周/表单存储，原始空字符串、0和多行内容保留。重启可恢复，统计与报表只读正式记录。读取失败的重试重新读取；保存失败保留输入并重试。正式记录与草稿冲突时让用户选择。

旧单计划迁移为 main，读取迁移不自动写回。每个计划独立保存科目、记录、会话、复盘与学习提醒；日签及备份提醒共用。创建不复制实际记录。暂停或运行中的计时先处理后切换，保存仍归原计划。新科目/归档/恢复采用日期有效区间，保留历史 ID、实际记录与旧复盘字段，不改写过去有效日期的统计。

ZIP2 恢复替换全部计划及日签；ZIP1 替换当前计划及日签；JSON 只替换当前计划。校验后显示实际计划数、覆盖范围及草稿影响；确认前不覆盖，取消或验证失败保持原数据。日志恢复失败时禁止写入并提供重新读取。

**文案与显示条件**

| 原表达或缺口 | 交付表达 | 条件 |
|---|---|---|
| 草稿没有退出恢复入口 | 草稿 / 已恢复草稿 / 清除 | 有实际草稿，不表示正式记录已保存 |
| 正式记录与草稿版本不同 | 记录已更新；使用草稿 / 保留当前记录 | 同字段冲突 |
| 手动保存说明段落 | 已保存或实际失败与重试 | 实际保存结果；未更改的重复保存不写入 |
| 归档科目仍显示参考0分钟 | 已归档 | 当天已归档但有记录需回看 |
| 丢弃计时附带已保存记录不变说明 | 丢弃这次未保存的计时？ | 用户主动丢弃时确认 |
| 没有备份日期 | 上次备份：日期或未导出 | 只在完整备份实际写完后更新 |
| 笼统替换当前记录 | 替换全部计划或当前计划、计划数、具体内容 | 恢复校验成功后确认 |
| 常驻来源/缓存总述 | 日期、真实署名、来源入口 | 日签及保存/分享图片沿用真实作者信息 |
| 日签没有查找入口 | 关键词 / 主题 / 语言 / 清除筛选 | 历史、收藏、开屏历史 |

完整对照和检索范围见 [文案审计](ux-copy-audit.md) 与 [中文源码行清单](validation-v1.3.1/visible-copy-source-inventory.tsv)。本轮没有重新加入“学习记录保存在本机”等说明；图文原文、用户随记及必要署名不做关键词删除。
