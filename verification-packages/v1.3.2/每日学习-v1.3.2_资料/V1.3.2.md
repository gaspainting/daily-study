# v1.3.2：单词数量与自填周目标

2026年10月14日发布。versionName 1.3.2，versionCode 6；上一正式版本 v1.3.1/code5。

**本轮交付**

单词改为「新学（个）」「复习（个）」两个主输入。新学目标默认每天50个，可调整默认值或单日目标；复习独立累计。两个输入分别提供 +5、+10、+20 按钮，适合分次记录；正式记录仍由「保存这一天」提交。周/月统计、历史、月历、小组件和报表同步按数量显示。

原先10周的教材章节目标及课表提示已清空。今日页提供「填写本周目标」，各周独立填写，编辑时提供「本周目标」「随记」。升级仅识别并清除原内置文本，已有自行修改的内容保留；新计划的周目标也从空白开始。

原技术栈为 Java Activity/WebView 与内置 HTML/CSS/JS，继续使用现有构建脚本。此次没有新增框架或服务端。

**记录与兼容**

学习数据格式保持 schema2，新增可选的科目 wordGoal、计划 wordTargets 和 manualWeekGoals 标记。旧 schema1 JSON、新旧 ZIP 仍通过原校验与确认流程恢复。

新学和复习均使用已有记录字段，空值与显式0分别保存，复习不抵扣新学目标。累加操作写入独立草稿，正式保存成功后才进入统计。失败保留输入；重复保存不重复累加。与后台更新后的正式值冲突时保留选择。

默认新学目标变更从今天起生效，过去日期目标保留；单日目标可设为0。相同默认值再次保存不会覆盖已有单日例外。旧单词分钟不换算成词数，有旧值时在「时长记录」中查看或修改，原计时会话保留。原有数学等科目的计时、休息边界和时长统计继续使用原规则。

旧内置周目标采用精确文本匹配的一次性迁移，读取时克隆数据；正式保存或恢复后保留迁移标记。自填目标、学习记录、复盘、会话及原参考分钟不在清理范围内。
