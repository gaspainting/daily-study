# v1.3.3：代码审查、单词操作与报表修正

2026年10月14日发布。versionName 1.3.3，versionCode 7；上一正式版为 v1.3.2/code6。继续使用 Java Activity/WebView、APK内 HTML/CSS/JS 和原构建脚本。

**本轮完成**

单词新学、复习各可撤销最近一次快捷累加。撤销恢复原始输入，空白仍为空白，显式0仍为0。每个单词科目可设置三个互不重复的正整数加数，旧配置默认5、10、20。数量与草稿保留原手动保存方式。

审查修复了独立表单草稿丢失、单日目标草稿日期混用、长文本草稿上限不一致、原生旧目标迁移与前端不一致，以及异常恢复期间的后台操作等问题。历史、计时明细、报表合计、日签检索、小组件刷新和重复草稿写入减少了重复工作。PDF导出改用随包保留许可的报表字体，修正中文复制/搜索时的字形映射。

审查覆盖全部生产Java、assets文本源文件、资源、构建/发布/打包入口和现有测试。逐模块范围、问题触发条件、修复与算法分析见 [代码审查](CODE-REVIEW-v1.3.3.md)。目录没有Git元数据；修改前107个文件摘要与原文件本机归档作为基线，既有改动与历史发行产物保留。

**记录与兼容**

数据仍为schema2，新增可选 `subject.wordSteps`，仅用于vocab科目。三个值均为1至100000整数，互不重复。学习记录、旧分钟、计时会话、新学与复习字段不变；复习不抵扣新学，休息安排不归零。

快捷操作仍只改变当前输入与独立草稿，正式记录在保存成功后更新。新学与复习分别撤销；直接编辑、成功保存、日期/计划切换与冲突处理重建撤销上下文。保存失败保留输入及仍有效的撤销，重启恢复草稿值，不恢复跨进程操作历史。

旧错绑日期草稿显示其记录日期，在用户选择前不套用到另一日期。目的日期已有不同草稿时先确认，取消保留两份；移动成功后才删除旧键，正式目标仍需手动保存。原备份格式、旧JSON、ZIP1/2、恢复范围确认、活动计时处理与取消保护保留。

**算法验证**

5000条日期记录、10000次计时，数据2629681字节，Node24.15执行9次取中位值。与v1.3.2查询结果逐项对照相同。

| 窄日期关键词历史 | 32.0ms | 33.2ms | 未测得加速，约慢3.6% |

报表合计从重复逐科扫描改为O(行数+科目数)。日签复用仅限同一次请求，组件复用仅限同一批刷新；未新增长期缓存。上述耗时为本机合成数据微基准，不代表vivo端耗时，原始采样见 [benchmark](validation-v1.3.3/algorithm-benchmark.json)。
