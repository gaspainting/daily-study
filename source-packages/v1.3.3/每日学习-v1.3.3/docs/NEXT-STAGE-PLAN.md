# 每日学习：下一阶段详细规划

2026年10月14日建议稿。当前版本 v1.3.3/code7。阶段A的操作与报表修正已交付，真机待验证；阶段B/C仍为规划，AI接口建议安排于v1.5.0。

**范围与交付顺序**

| 阶段 | 交付 | 完成条件 |
|---|---|---|

**A1 · 单词累加与撤销**

保留今日页的「新学（个）」「复习（个）」主输入。每行继续显示三个快捷加数，有可撤销操作时显示「撤销」。撤销当前字段最近一次快捷累加，新学与复习各保留一次撤销机会。

| 操作 | 新学输入 | 复习输入 | 正式记录 |
|---|---|---|---|
| 两项初始为空 | 空白 | 空白 | 未记录 |
| 新学 +10 | 10 | 空白 | 未记录 |
| 复习 +20 | 10 | 20 | 未记录 |
| 撤销新学 | 空白 | 20 | 未记录 |
| 保存这一天成功 | 空白 | 20 | 新学未记录；复习20个 |

撤销恢复累加前的原始输入。原值为显式0时恢复0，原值为空白时恢复空白；不采用简单减法推断之前状态。连续点击新学 +10、+20 后，撤销一次恢复10。

直接修改某一输入后，清除该字段的快捷撤销机会。成功保存、切换日期或计划、选择冲突处理结果后，撤销上下文重建。保存失败保留输入及仍有效的撤销机会。重启恢复草稿值，第一版不跨进程恢复撤销操作历史。

新学、复习、随记、安排及旧分钟仍由「保存这一天」提交。快捷加数不打开键盘；读屏播报字段及当前数量。无效输入先提供该字段错误，超过上限时保持原值。狭窄屏幕允许按钮换行，触控尺寸沿用现有44px要求。

**A2 · 自定义快捷加数**

入口放在「计划 → 科目与目标 → 单词」，与每日新学目标相邻。每个单词科目保存三个正整数快捷值，默认5、10、20；新学和复习共用这组按钮。用户可设为1、5、10等。保存配置后不修改已输入或已记录的数量。

配置按科目和计划隔离，保存时验证整数、范围及重复值。复制科目模板创建计划时可沿用快捷值，学习记录仍为空。旧备份缺少配置时采用5、10、20。

建议以可选科目配置扩展现有数据，前端与原生同时验证；完整备份携带配置。单词实际记录继续使用已有 newWords/reviewWords 字段，避免新建另一套每日总量。

**A3 · 真机验证与PDF**

模拟器可继续验证模型、页面和系统交互；真机回归在连接 vivo X100s / Android16 后执行，未连接时保留「未验证」记录，不将模拟器结果替代真机结果。

| 场景 | 检查结果 |
|---|---|
| App内更新 | 手机网络下检查、下载取消、安装权限设置返回、取消安装、同签名覆盖安装后数据保留 |
| 计时与后台 | 暂停/继续、切换其他App再返回、锁屏、休息边界前后；单词数量不被计时改写 |
| 提醒 | 主动开启、拒绝权限、设置返回、关闭后取消、休息时段不补发 |
| 小组件 | 系统取消与确认添加、词数/时长单位、正式保存后刷新、跨日更新 |
| 输入与恢复 | vivo键盘、累加不呼出键盘、草稿重启、备份恢复取消/失败、空白与0 |
| 大字号与读屏 | 系统200%字体、按钮换行、输入单位、撤销状态与实际保存反馈 |

PDF检查沿用现有黑白A4样式，定位中文文字映射问题。选用可用于随APK分发的字体或其他文本输出方式时，核对授权及包体变化。验收同时包含视觉渲染、中文搜索/复制、新学/复习/分钟、长文本折行与多页；复制文本与源中文逐字比较。

**B1 · 自填周目标清单**

今日页继续使用「本周目标」区块。保留用户已写的整体目标；新增清单可承载具体任务，科目关联为选填。示例内容由用户填写，App不内置教材章节。

示例布局：

```text
本周目标                    10.12—10.18
复习我正在使用的教材第三章

☑ 整理第三章公式              高数
□ 完成第三章例题              高数
□ 回顾本周易忘词              单词

1 / 3 项已完成
编辑目标
```

上述内容仅为规划示例，不写入初始计划。勾选形态和计数用于展示操作，实际正式状态由保存结果确定。

编辑页包含「本周目标」文本、任务列表、「添加任务」及「随记」。任务可改标题、选择科目、上下移动和删除；文字与清单都可使用，也可保持空白。沿用现有底部导航与编辑弹层，适配黑白细线样式。

拟沿用手动保存：勾选或编辑后产生草稿，出现「待保存」和「保存目标」；提交成功后反馈「已保存」。今日目标编辑与每日学习记录分别保存，周复盘只引用已保存任务状态。目标写入失败时保留清单并提供重试，重复保存不重复创建任务。

勾选任务不填写单词数量或学习分钟。关联科目归档后保留任务及科目名称。进入新的一周时，任务初始为空；不自动复制或延期未完成项。历史任务可查看和手动修改。

编辑中删除任务只改变待保存清单，提供「撤销删除」。涉及批量清空已保存目标时，确认具体范围。任务顺序变化不更换任务ID，草稿恢复和冲突检测以稳定ID匹配。

**B2 · 今日、复盘与日期归属**

今日页显示选中日期对应周的目标。周复盘增加目标完成项、未完成项及既有随记；没有任务时只保留填写入口，不补入预设内容。新学、复习和分钟继续各自统计，目标完成数单独显示。

当前代码 weekInfo() 按 plan.startDate 划分连续7天，教学周编号由 startWeek 计算。新的目标归属继续显示具体日期范围；仅修改起始教学周编号时，目标日期和完成状态不变。

修改计划开始日期会改变现有周分组，拟采用以下处理：目标保留原日期归属，旧目标从「历史目标」入口可见。若用户主动选择迁移到新周，确认实际迁移范围；冲突时选择目标处理方式，取消保持原数据。延长或缩短计划不删除既有目标，缩短后超出范围的目标仍可回看。

第一版不自动推断文字中的数量，不根据勾选计算学习用时。用户在任务中写「学习50个新词」时，该任务仍由用户勾选，新学实际值由词数记录输入。

**B3 · 数据与旧内容**

建议为清单采用学习schema3，明确区分旧的文字目标与清单数据。保留 weekGoals/weekHints 的原文字和随记，增加带稳定ID、标题、可选科目、勾选状态及日期范围的任务结构。任务状态变更时间表示记录操作时间，不伪造任务的实际完成时间。

读取旧schema1/2时克隆迁移，旧文字继续作为本周整体目标；不按换行自动拆任务，不自动勾选。正式保存或恢复后再持久化新结构。新计划不继承实际记录、复盘及已完成任务。

草稿按计划、周和表单隔离，保存任务状态与原记录版本；外部数据更新时逐任务处理冲突。完整备份包含全部计划的文字目标和任务；新版继续读旧ZIP/JSON，导入新版清单备份时校验结构并明确覆盖范围。取消及失败保留原数据。旧App不支持的新数据需明确报版本不支持，避免静默丢弃字段。

周PDF报表可增加自填目标与清单状态。现有学习CSV列及数值语义保留；不把勾选数混入分钟或新学数量。

**后续候选的进入条件**

单词分次明细需要先确定「快速输入」「正式提交」「手动修订」三者的关系：累加产生输入草稿，保存后才提交明细；修改总量要记录修订来源，旧总量不伪造成多次学习。仅有保存时间的旧记录不能推算学习时段。

通用数量科目在需要记录题数、页数等时单独开发。科目类型、计量方式与单位分开，新学/复习继续为单词专有字段；单位改变应保留历史单位。现有科目分钟不直接换算为题数或页数。
