# 每日学习 Android APP

为个人学习制作的离线安卓打卡工具。界面采用黑白纸张风格，内置2026-10-12至2026-12-20的高数与单词低强度计划；可安装APK的最低系统为Android 8.0，目标系统为Android 16。主要使用设备为vivo X100s。

## 安装与使用

1. 将 `dist/每日学习-v1.0.0.apk` 传到手机，点击文件安装。根据手机提示允许此次安装来源，安装后桌面名称为“每日学习”。
2. “今日”查看参考量，选择科目开始计时；离开界面、锁屏后仍可从通知栏暂停或结束。暂停时间不计入净学习时间，结束后将本次时间加入当天该科实际记录。
3. 每科实际分钟可手动填写，也可展开详细字段记录内容、问题、新词、复习词及易忘词。留空表示未记录，0表示明确未学习。填写当天状态、休息情况及原因后保存。
4. “计划”浏览70天或任意自定义日期范围，进入历史日补记；修改单日参考分钟、周目标、科目和日期。修改科目的每周默认分钟用于新增日期；既有单日参考量可单独调整，历史实际记录保留。
5. “复盘”查看每周参考与真实实际量、已记录天数，填写强度、需要回顾的问题及下周调整。允许减量、仅回顾或休息。
6. “设置”开启或关闭学习提醒、调整时间、导出或恢复JSON备份、添加桌面小组件。提醒初始关闭；开启时由Android询问通知权限。

## 休息与记录规则

- 工作日20:30及以后不启动学习计时，不发送学习提醒。
- 周末09:30以前、19:00及以后不启动计时或发送学习提醒。
- 正在运行的计时到休息边界自动暂停。周日下午建议保留完整休息；每周至少半天休息由复盘记录。
- 手动记录可随时保存，包括如实补记在边界外发生的学习。计划参考分钟不会自动填入实际量。
- 不生成补量任务，不设置连续打卡惩罚或硬性完成率，不要求十周学完高数。
- 周末数学长块可主动暂停分段，休息时必须暂停；计时器不能判断人是否真实在学习。

## 数据与备份

数据保存在应用私有目录，APP没有网络权限。不会自动上传记录，也不会扫描手机文件。

导出备份通过Android系统文件选择器保存JSON，内容包括计划、参考量、实际记录、周复盘、提醒设置和已完成的计时会话。运行中尚未结束的计时不包含在备份里。

恢复前会检查文件格式并显示计划日期与记录天数。确认后替换当前计划和记录；请先导出当前数据。必须结束当前计时才能导入。卸载或清除应用数据会移除本地记录，换机前需要导出备份。

桌面小组件显示今日实际/参考和状态，点击打开APP。可从设置请求添加，或长按桌面空白处进入“小组件”选择“每日学习”。

系统可能延迟普通学习提醒；该版本采用非精确提醒，触发时会再次检查休息边界，迟到过久直接略过。在vivo设备上，如系统省电策略终止应用，需以实际情况核对时间；可在系统中按个人需要允许后台运行。

## 构建

不依赖云服务或在线前端库。APK使用Java原生宿主、Android前台计时服务、系统提醒与小组件，界面HTML/CSS/JS打包在APK内，可完全离线工作。

本机已有JDK21与Android SDK36，使用以下命令直接构建：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
node --test .\tests\model.test.cjs
```

`build.ps1 -TestBuild` 会额外生成可调试的测试APK，含Android仪器测试；正式APK不带测试入口且关闭WebView调试。

个人安装签名保存在 `.signing/personal-release.p12`，不包含在源码分享包中；保留该文件便于后续直接覆盖升级，避免卸载丢数据。源码构建自动生成新的个人签名时，不能直接覆盖不同签名的旧安装，应先备份数据。

原始参考数据来自上级目录 `output/每日打卡表_独立会话交接说明.md`。`generate_seed.py` 提取原文70日数据，并核对日期连续性及十周逐项合计；不写入实际记录。

验证结果与截图将保存于 `docs/`，正式安装包和SHA256在 `dist/`。
