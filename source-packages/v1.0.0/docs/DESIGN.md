# 界面设计依据

优先采用用户指定的黑白纸质打卡表风格。ui-ux-pro-max的设计系统检索与手机可访问性规则用于触控、表单、焦点和导航；检索中的彩色、在线字体和营销落地页建议不适用于本离线工具，因此采用纸张底色、深色文字、细线与系统字体。

主色：纸张#F8F7F3，正文#20201E，辅助文字#66655F，细线#D7D5CE。用数字、线和留白组织内容。按钮、日期和标签保持稳定位置；图标为同一套单色SVG。

今日页优先显示参考量、实际量和计时入口，详细学习字段可展开。计划、复盘与设置采用底部导航；表单保持44px以上触控空间，提供显式标签、数字键盘和可见焦点。

空记录、实际0和休息状态分别展示；缺失数据以文字说明，不用0柱或达标颜色暗示。参考时间只作分配依据，不将其自动转化为最低量、失败提示或连续签到压力。

适配安卓系统状态栏、手势导航和软键盘，内容与底部导航避免覆盖。字体使用设备内置字体，所有前端资源打包入APK，不加载CDN。
