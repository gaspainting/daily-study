# 第一版验证记录

验证日期：2026-10-13。目标设备：用户的vivo X100s / Android 16。测试环境：Android 16 API36 x86_64模拟器与真实APK内WebView；另有中文、Asia/Shanghai时区的独立手机尺寸浏览器预览。未连接用户的vivo真机。

## 已通过

- 数据模型12组测试：70天逐日参考值、10周加总、空白与0、净分钟、分数分钟、科目增加、历史保留、日期扩展、休息与提醒边界、严格备份校验。
- Android原生35项检查：私有目录原子写入、初始实际为空、十周参考量、工作日/周末边界、计时开始/暂停/继续/结束、休息不计时、重复结束不重复计量、边界自动暂停、提醒默认关闭、原生提醒通知及每天去重。
- 真APK内页面22项检查：四页加载及无横向越界、手动补记、参考调整、目标编辑、添加科目、扩展日期、周复盘、提醒验证、计时后台恢复、真实分钟保存、无未捕获脚本异常。
- 手机浏览器预览24项检查：393px/320px宽度、未保存编辑保留、多表单独立保存、计时精度、历史空白/0、图表、完整备份及脚本/CSP检查。
- Android系统文档选择器导出JSON与确认导入，实际恢复内容逐字段完全一致（数据版本字段由本地重写）。
- Android桌面实际添加4×2小组件，能显示日期、科目实际/参考、状态及打开APP入口。
- 正式APK签名v2/v3验证成功，minSdk26 / targetSdk36；正式包没有调试标志、测试入口或网络权限。

## 成品检查

四页截图在 `screenshots/`，真实页面检查结果在 `ui-test-results.json`。已目视检查标题、中文字体、日期、参考/实际区分、图表、底部导航、填写区域与桌面小组件。首屏增加高数/单词计时入口；休息时段禁用计时按钮，仍允许查看与真实补记。

测试数据只写入测试设备；发行APK的种子数据中 `records`、`reviews`、`sessions`均为空。发行包不包含运行中的计时。

## 验证的边界

模拟器验证了Android16通用系统接口，vivo实际后台省电与桌面布局仍需用户真机使用后确认。学习提醒采用普通非精确闹钟，系统可能延后触发；过休息边界或迟到过久会略过。计时器累计运行时间，用户休息时需要暂停，不能自行判断是否真实学习。

本版为基础学习打卡版本；新增“每日激励”目前仅有需求评估文档，没有联网图文或启动动画代码。
