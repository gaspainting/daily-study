# 每日学习 v1.2.0 开发与验证说明

交付日期：2026年10月14日。包名 cn.edu.njupt.studycheckin，versionName 1.2.0，versionCode 3，minSdk 26，targetSdk 36。用户确认手机现有版本为 v1.1.0，本轮以此为升级起点。关于页从 PackageInfo 取版本，构建文件名从 Manifest 取值。

**实际修改**

保留纸张黑白视觉、细线和原有品牌句一处。删除常驻开发说明、安慰与流程预告；不是改写成长句、隐藏字体或统一搬进帮助。按用户二次反馈，设置中的「学习记录保存在本机，不提供云同步」也整段删除。

今日汇总区使用「参考时长 / 已记录」，未记录不带分钟单位，明确 0 显示 0 分钟，部分填写显示 n/m 科目已记录。表单只在真正保存成功后显示已保存；错误保留输入并提供重试；重复提交不写入重复会话。日期或复盘周次切换后清除上一份保存反馈。安排、休息记录和随记只变标签，原字段和枚举保留。

计划范围外只显示计划状态。复盘天数指标改为「时长记录天数」，与其单位一致。图表向无障碍树提供逐日实际/参考信息，未记录和 0 的绘制仍分开。

休息边界保持工作日20:30起，周末09:30前、19:00起。相关原因在不能开始/继续计时时显示；自动暂停以已持久化暂停状态为准。正常设置页通过「休息时段」查看规则。

日签不再以「原创」作通用标题，删除本地留存、抽取成功后的流程说明、缓存容量及内部去重术语。文字作者和图片作者直接显示；详情、保存图片及系统分享按真实来源保留署名、出处、许可、中文释义，排版明确为每日学习。没有改为离线插画，图片来源和筛选逻辑沿用真实联网素材。

提醒权限由主动开启动作请求，普通保存不反复请求；权限关闭时给出真实状态和系统设置入口，普通调度限制位于主动打开的「未收到提醒？」。没有增加精确闹钟等权限。小组件区仅保留动作及添加帮助：发起请求不等于成功，成功回调须验证真实小组件ID与提供者。

备份区保留导出/恢复动作。覆盖前按完整 ZIP 或旧 JSON 显示实际影响范围；无确认不覆盖，活动计时先保存或确认丢弃。损坏备份校验失败使用持续可见的错误对话框，提供重新选择和取消。原格式、校验、恢复日志与取消保护保留。

大字号通过系统 fontScale 传给 WebView，并调整放大后的日期、指标、时间输入与科目布局。删除正文后同时移除空状态行和重复分隔线。

**文件与对照**

主要修改位于 app/src/main/assets/app.js、inspiration.js、index.html、新增 polish.css；原生 MainActivity、AppRules、TimerStore、TimerService、ReminderReceiver、ReminderScheduler、StudyWidget、InspirationPoster、InspirationSources、InspirationStore，以及新增 WidgetPinReceiver。Manifest 和 build.ps1 处理版本、回调注册和构建命名。

完整文件差异清单见 validation-v1.2.0/changed-files.json；文案前后对照与出现条件见 [ux-copy-audit.md](ux-copy-audit.md)。本轮检索今日、计划、复盘、计时、设置、日签/开屏/历史/详情、通知、小组件、导出以及读取/校验异常；字符串清单见 validation-v1.2.0/visible-string-inventory.txt。用户计划、随记与日签原文不参与机械删词。

DataStore、BackupManager、model.js、原始70日种子和图文文字库未作数据迁移；计划实际记录初始为空，存储 schema 沿用 version 1。应用级云同步未增加，Manifest allowBackup=false；系统厂商设备迁移不能由这一标志完全限定。此技术核查不作为常驻界面说明。

**验证环境与执行**

Windows，JDK21，Android SDK36，Android16/API36 Pixel5模拟器 emulator-5572。真实 Java/APK/WebView 与系统权限、文件选择器、相册、分享及桌面 Launcher 验证；没有将浏览器预览当作手机测试。

执行命令与最终结果由本目录 validation-v1.2.0/ 下各原始报告记录，交付汇总见 validation-v1.2.0/test-summary.json。正式构建命令：powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1；测试构建增加 -TestBuild。正式APK另检查包名、版本、签名、调试标志、测试入口、种子及打包资源。

本轮出现并修复的实际问题：保存反馈跨日期/周次残留；复盘指标标题单位不匹配；无内容仍生成历史/许可容器；坏备份错误提示转瞬消失；大字号日期/品牌标记布局。测试脚本也修复了旧版本页脚断言、整段历史只有一条的假设、Launcher 实际按钮名称与删除后的 Undo 延迟。中间失败不作为通过结果，最终重跑结果单独留存。
