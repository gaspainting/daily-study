# 每日学习开发范围

当前发行版本：v1.3.1 / versionCode 5。用户以功能截图限定本轮八项，并追加多计划切换。

**已交付**

| 版本 | 功能 | 入口与行为 |
|---|---|---|
| v1.3.0 | App 内更新 | 设置 → 关于 → 检查更新，HTTPS 下载与校验，系统安装确认 |
| v1.3.1 | 自动保留草稿 | 表单输入后独立保存，按计划与表单恢复；正式记录手动保存 |
| v1.3.1 | 历史搜索与筛选 | 复盘 → 历史，日期/科目/关键词/安排/记录状态 |
| v1.3.1 | 月历与月统计 | 复盘 → 月历，记录分布、各科参考与实际、记录天数 |
| v1.3.1 | 科目归档、排序与复盘适配 | 计划 → 科目与默认参考，归档/恢复/上移/下移；按科目回顾 |
| v1.3.1 | 计时明细 | 复盘 → 计时明细，日期、科目、净时长、结束时间 |
| v1.3.1 | 备份管理 | 上次成功备份日期，7/14/30 天可选提醒，完整备份含全部计划 |
| v1.3.1 | CSV/PDF 学习报表 | 设置、周复盘、月历的导出入口；日期和科目可选 |
| v1.3.1 | 日签搜索与筛选 | 历史/收藏/开屏历史中的关键词、主题与语言 |
| v1.3.1 | 多计划切换 | 顶部计划名称，最多 8 个，各计划独立记录、草稿、统计与学习提醒 |

**暂缓**

App 内置 AI 暂不开发。本轮不接入 AI 服务、模型密钥或付费推理。原有日签素材和真实出处继续沿用。

**发布与后续验证**

继续使用 [gaspainting/daily-study-releases](https://github.com/gaspainting/daily-study-releases)，公开资源限 APK、版本清单及更新说明。发行命令见 [更新通道](APP-UPDATES.md)，实际测试及未验证项见 [v1.3.1 报告](V1.3.1.md)。下一版本号按下一次实际发布确定。
