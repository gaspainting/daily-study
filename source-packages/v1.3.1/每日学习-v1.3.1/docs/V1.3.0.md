# v1.3.0：App 内更新与公开发布通道

日期：2026年10月14日。versionName 1.3.0，versionCode 4。上一轮交付为 v1.2.0 / code 3。

**本轮范围**

「设置 → 关于」新增检查更新、更新说明、下载进度、取消、重试及安装入口。发布仓库 [gaspainting/daily-study-releases](https://github.com/gaspainting/daily-study-releases) 只承载 APK、版本清单及更新说明，源码和签名私钥保留本机。

用户同意的草稿恢复、历史筛选、月历、计时明细、科目归档、报表、日签筛选等已进入 [后续开发清单](NEXT-DEVELOPMENT.md)，本版本未实现这些项目。

**实现与状态语义**

使用原有 Java Activity / WebView 技术栈。原生层访问固定 HTTPS 发布地址，后台下载不写学习状态；校验清单、字节数、摘要、APK 包名与版本，并比对签名证书；最终安装签名验证由 Android 执行。下载完成只显示「下载完成」，进入系统安装界面不显示「已安装」。关于版本仍来自实际 PackageInfo。

仅主动安装时打开未知来源安装权限入口，返回后仍由用户点击继续。安装前保留未保存输入并阻止安装；活动计时需保存或明确丢弃。原生层在打开安装器前再次检查活动计时。取消和下载失败保留原应用与正式学习记录。

新增 REQUEST_INSTALL_PACKAGES 权限及只读 APK Provider；没有加入静默安装、账号、云同步或后台服务器消息推送。学习 schema 1、ZIP/旧 JSON、休息规则及提醒调度保持既有实现。

**实际修改文件**

- `app/src/main/AndroidManifest.xml`：1.3.0/code4、安装请求权限及只读更新 Provider。
- `MainActivity.java`：原生更新桥、主动安装权限入口、安装前计时检查、防重复发起、返回后读取状态。
- `UpdateManager.java` / `UpdateApkProvider.java`：异步 HTTPS 获取、取消、缓存、APK 元数据和证书核对、只读安装 URI。
- `assets/app.js` / `polish.css`：关于页更新状态、说明、下载进度和操作，保留表单输入，大字号排版。
- `build.ps1`：仅测试构建注册独立更新 instrumentation；正式包没有该入口。
- `scripts/prepare-release.ps1` / `publish-release.ps1` / `release-common.ps1`：真实构建信息生成、三文件公开发布及核对，失败草稿恢复。
- 新增更新原生/签名包/UI/实际安装/发行工具测试；维护 README、使用说明和后续范围。源码打包工具只生成本地交付材料，不上传。

学习模型、DataStore、TimerStore、提醒调度、备份格式、图文数据来源与默认计划未改。既有 v1.2.0 安装包和报告保留；本项目仍无 Git 元数据。

**新入口的文案和出现条件**

| 原状态 | 当前显示 | 出现条件 |
|---|---|---|
| 关于页仅显示版本 | 检查更新 | 关于页初始状态 |
| 无联网检查反馈 | 正在检查更新… / 取消 | 请求未结束 |
| 无可用版本反馈 | 已是最新版本 | 成功读取清单，versionCode 不高于已安装值 |
| 无更新说明与下载入口 | 新版本、说明、下载更新 | 清单通过检查且 code 更高 |
| 无下载进度 | 下载中 n% / 取消下载 | 实际收到的字节数 / 总字节数 |
| 无安装授权入口 | 安装权限未开启 / 开启安装权限 | 下载核对完成、系统授权未开启 |
| 无安装入口 | 下载完成 / 安装更新 | 已核对 APK 且权限允许 |
| 无更新重试入口 | 具体失败状态 / 重试 | 网络、大小、摘要或包信息检查失败 |
| 无安装时表单保护 | 页面有未保存的修改，请先保存。 | 用户主动安装时仍有未保存输入 |
| 无安装时计时选择 | 当前计时尚未保存 / 取消、保存并继续、丢弃本次计时 | 安装时有活动计时；丢弃需另行确认 |

系统设置返回后刷新授权状态；打开设置或安装器都不显示「已安装」。取消安装后保留 APK，可再次安装。关于页版本从当前包元数据读取。

最后一组使用“当前更新代码 + 1.2.0/code3 元数据”的模拟器测试引导包，升级目标是实际公开 v1.3.0/code4 正式 APK。该引导包不等同于旧版正式 v1.2.0，也未发布。通过系统安装界面完成覆盖；安装后学习文件与图文文件摘要逐字节一致，20 个实际图片文件摘要不变。正式包启动后能读取原记录、显示真实 1.3.0，并通过公开地址返回「已是最新版本」。

更新 UI 的 9.9.9 与大字号长说明是夹具，只验证排版和状态，不作为实际下载或安装证明。真实联网、权限及覆盖结果来自 `update-install-ui-results.json`。测试断言存在重叠，不等同于互不重复的功能数量。

首次发布发现草稿未建 Git 标签时，按标签读取返回 404；工具已改为按发行 ID 读取和发布，并增加字节流下载和严格 `-ResumeDraft`。修复后 30 项工具检查通过，三个草稿资源重新下载核对，再正式发布。端到端脚本初次因 ADB 转义、Windows 换行及权限撤销导致旧调试连接失效而中断，修复测试辅助代码后完整 23 项通过；并未修改 App 逻辑来绕过断言。

模拟器为 API36/userdebug，正式 APK DEBUGGABLE=false、代码按此关闭 WebView 调试，但该系统 WebView 仍强制提供调试端点，供本轮取证；实体正式系统上的端点状态尚未验证。实体 vivo X100s 未连接，手机网络、厂商安装界面、后台调度、实际语音输出和手势、Android8–15 的安装行为均未验证。未发现其余未解决的发布阻碍。
