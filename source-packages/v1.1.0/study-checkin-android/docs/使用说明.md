# 每日学习 v1.1.0 使用说明

交付日期：2026年10月14日。适用设备：安卓手机，最低Android 8.0；目标设备为vivo X100s / Android 16。已在Android 16模拟器验证，vivo真机尚未连接。

**一、安装和覆盖升级**

把“每日学习-v1.1.0.apk”传到手机，使用文件管理器打开，按系统提示允许此次安装来源并完成安装。桌面名称为“每日学习”。

已经安装v1.0.0时，先在旧版设置中导出JSON备份，再直接安装新版进行覆盖升级。两版包名和签名相同，新版保留已有学习计划、实际时间、复盘、提醒设置及已完成计时会话。无需先卸载；卸载或清除应用数据会删除本地记录。

★ APK安装包和源码ZIP不同：手机安装APK；源码ZIP用于查看或继续开发，不需要解压源码才能使用APP。

**二、今日打卡和计时**

“今日”显示日期、当日参考分钟和各科实际记录。高数、单词及新增科目都可开始计时，也可手动输入实际分钟。运行计时可以暂停、继续或结束；暂停时长不会算入净学习时间，结束后本次净分钟加入当天对应科目的实际记录。

开始计时会请求通知权限，便于离开APP或锁屏后从通知栏暂停、结束。拒绝通知权限仍可在APP内操作；vivo的后台与省电策略应以真机表现为准。

★ 参考分钟用于安排，不会自动写入实际记录。留空表示尚未记录；0表示明确没有学习。可以选择减量、仅回顾或休息，不需要追赶差额。详细字段可记录学习内容、问题、新词、复习词及易忘词；编辑后点击保存。

**三、计划、历史和每周复盘**

初始计划为2026年10月12日至12月20日，共70天，包含高数和单词。进入“计划”可浏览日期并打开历史日补记，也可修改日期范围、单日参考分钟、周目标或添加科目。修改科目的每周默认分钟影响新增日期；既有参考安排可逐日修改，实际记录保留。

“复盘”比较每周参考与实际净分钟，查看已经记录的天数，填写强度、值得回顾的问题、休息情况和下周调整。统计依据实际记录，不把未填数据当作已学习，也不设置连续打卡惩罚。

工作日20:30及以后保护休息；周末09:30以前、19:00及以后不启动计时或发送学习提醒。计时达到休息边界自动暂停。手动补记始终可用，可以如实记录已经发生的学习。每周至少半天休息由本人安排并在复盘记录。

**四、开屏图文和今日日签**

重新启动APP时随机显示图文，图片就绪后展示5秒，可以随时点击“跳过”。后台返回、锁屏后返回、关闭分享面板或文件选择器时直接进入原页面。开屏长文只显示标明的节选，完整文字保留在“开屏回看”。

首次安装还没有图片时，APP立即联网准备素材，并显示可跳过的获取状态。等待超过8秒会先进入学习页面；完全没有图片时不生成替代画面，也不消耗抽签机会。

底部“日签”包含“今日日签、日签历史、收藏、开屏回看”。点击“抽取今日日签”后，完整图文保存成功才算抽取；每天以手机本地日历日期为准，只保留一张固定日签。当天反复查看或重开APP都不会换卡。

图片来自Lorem Picsum的真实照片和Met开放艺术作品。默认开启联网准备；日签页可以手动“准备新图文”，也可以关闭联网。APP没有内置日签插画，不在本地生成插画。下载成功的实际图片会保留，支持历史、收藏及断网回看。

图片和文字分别记录使用历史，优先取未展示内容。没有新图片时先联网补充；来源失败且已有真实图片缓存时，可以复用较久未展示的图片并标记。不能保证有限素材永不重复。图文允许独立搭配，主题不限，也不要求图片一定描绘文字内容。

文字优先获取一言中文语句，同时有81段AI辅助原创文字作为补充，其中25段外文附中文释义。没有中文释义的外文候选不能参与抽取。当前未接入实时AI生成、付费接口或任意外语在线翻译。

**五、收藏、保存图片和分享**

点击日签或历史条目查看全文；外文同时显示中文释义。“图文来源与说明”保留图片作者、作品名、来源页面、使用说明，以及文字出处。

日签和开屏图文都可以收藏；取消收藏只改变收藏状态，不删除历史。保存图片会生成包含完整原文、释义、日期及来源的图文卡。较长内容会分成多张带页码的图片，避免缩小到难以阅读或丢失后半段。

Android 10及以上直接写入相册的“每日学习”目录，不请求读取其他相册的权限；Android 8/9使用系统分享方式保存。点击分享会打开安卓系统分享面板，由你选择接收应用；取消不会改变日签。

日签页的“清理未使用素材”移除未展示候选及不再被图文引用的图片，保留历史和收藏。临时分享图片超过7天后在后续启动时清理，不影响已抽到的原始图片。

**六、完整备份和恢复**

在设置中导出ZIP完整备份，通过系统文件选择器选择保存位置。ZIP包含学习数据、已完成计时会话、实际图文图片、日签与开屏历史、收藏和去重记录。运行中尚未结束的计时不包含在备份中，建议先结束计时再备份。

★ 换机、卸载或清除应用数据前，请导出ZIP并将其保存到应用之外。只有截图不能恢复计划和记录。

恢复支持v1.1.0的完整ZIP和v1.0.0的JSON。必须先结束当前计时。选择文件后，APP校验内容并显示计划日期、记录天数和图文条数；确认完整ZIP恢复会替换当前学习记录、图文与收藏。旧版JSON只替换学习数据，保留已有图文。恢复前建议先导出当前数据备份。

学习记录和图文均保存在手机私有目录。联网仅用于素材获取，不把学习计划、实际时间或复盘发送给素材来源。

**七、提醒和桌面小组件**

学习提醒初始关闭，可在设置中自行启用和修改时间。启用后需要通知权限；提醒遵守休息边界，使用系统普通提醒，可能因省电策略延迟，过度迟到的提醒会略过。

小组件显示今日实际/参考分钟和状态，点击打开APP。可从设置请求添加，也可长按手机桌面空白处，从“小组件”中选择“每日学习”。

**八、遇到图片获取问题**

先确认手机可联网、日签页“联网准备”已开启，再点击“准备新图文”。公开素材服务可能暂时不可达；失败会提示重试，不占用当天资格。已经抽到的卡片保留原图，不因下一次联网而替换。首次无缓存时，可以先正常使用学习功能，之后再抽取。

详细来源核查见同目录“插图来源与选择核查.md”；功能、测试依据和当前限制见“每日学习-v1.1.0_开发与验证说明.md”。
