# 每日学习 Android APP

为个人学习制作的安卓打卡工具，当前版本v1.1.0。学习记录离线保存，新增“每日激励”图文模块，可联网准备素材。界面采用黑白纸张风格，插图可以彩色；内置2026-10-12至2026-12-20的高数与单词低强度计划。最低Android 8.0，目标Android 16，主要使用设备为vivo X100s。

## 安装与使用

1. 将 `dist/每日学习-v1.1.0.apk` 传到手机，点击文件安装。已经安装v1.0.0时可以直接覆盖升级，签名保持一致；安装后桌面名称为“每日学习”。升级前建议先导出已有记录备份。
2. “今日”查看参考量，选择科目开始计时；离开界面、锁屏后仍可从通知栏暂停或结束。暂停时间不计入净学习时间，结束后将本次时间加入当天该科实际记录。
3. 每科实际分钟可手动填写，也可展开详细字段记录内容、问题、新词、复习词及易忘词。留空表示未记录，0表示明确未学习。填写当天状态、休息情况及原因后保存。
4. “计划”浏览70天或任意自定义日期范围，进入历史日补记；修改单日参考分钟、周目标、科目和日期。修改科目的每周默认分钟用于新增日期；既有单日参考量可单独调整，历史实际记录保留。
5. “复盘”查看每周参考与真实实际量、已记录天数，填写强度、需要回顾的问题及下周调整。允许减量、仅回顾或休息。
6. “日签”每天抽取一次，当天固定；可查看日签历史、收藏和开屏回看。原文与外文中文释义完整保存，长文在详情滚动阅读；可保存图文到相册或打开系统分享面板。
7. “设置”开启或关闭学习提醒、调整时间、导出ZIP完整备份、恢复ZIP或旧版JSON、添加桌面小组件。提醒初始关闭；开启时由Android询问通知权限。

## 每日激励

重新启动APP显示随机图文，图片就绪后展示5秒，可立即跳过。从后台、锁屏、文件选择器或分享面板返回不重播。开屏长文显示节选，全文在“开屏回看”保留。启动展示不影响已有计时。

以手机本地日历日期为一天。每天只有一个固定日签；再次点击、重开APP或重启手机都读取原卡。图片和文字分别通过来源标识及内容摘要检查历史；优先使用未展示内容，新图片获取失败时可使用较久未出现的联网缓存图片并标记复用，不承诺永不重复。

APP不内置离线插画，也不在本地生成替代图片。图片来自联网取得的真实照片或公开艺术作品；取得后保存在手机，用于历史回看和断网时使用。首次使用尚无图片时，会显示获取状态并允许跳过；超过8秒仍未准备好会进入学习页面，获取失败不会消耗抽签机会。

文字优先取一言中文语句，也保留81段AI辅助原创文字，包括25段附中文释义的外文内容，覆盖中文、英文、日文、法文、西班牙文、韩文、德文、意大利文和俄文。原创文字仅用作外文配套或语句来源故障的补充，始终搭配真实联网图片；不生成离线插画。

联网准备默认开启，首次需要图片时立即准备，其后每次启动尝试补充少量素材；可以在日签页关闭，也可以点击“准备新图文”手动补充。图片来源为Lorem Picsum照片和Met开放艺术作品。优先选择未展示图文，尚无新图片时先联网获取；来源故障且已有图片缓存时，使用较久未展示的联网缓存图片并标记复用。完全没有图片时保留当天资格，显示重试提示。

图文允许独立搭配，主题标签不表示插图一定描绘该句文字。当前没有接入实时AI生成或任意外语的在线翻译服务；外文采用已经准备好中文释义的原创内容，缺少释义的候选不参与抽签。不能保证单个网络来源覆盖所有主题或长期连通。

收藏同时适用于日签和开屏图文。历史保存实际图片，回看和导出不会换成另一张随机图。相册保存包含完整原文、释义、日期和来源；较长内容自动分成多张带页码的图片。Android 10及以上直接写入本APP创建的相册图片，不请求读取其他相册的权限；Android 8/9使用系统分享方式保存。

分享按钮生成图文后打开安卓系统面板，由用户选择目标，不自动发送给任何人。临时分享图片在APP缓存中保留，超过7天的临时导出在后续启动时清理；已抽取的历史和收藏图片不作为临时素材自动淘汰。“清理未使用素材”只移除未展示候选及不再被图文记录引用的图片。

## 休息与记录规则

- 工作日20:30及以后不启动学习计时，不发送学习提醒。
- 周末09:30以前、19:00及以后不启动计时或发送学习提醒。
- 正在运行的计时到休息边界自动暂停。周日下午建议保留完整休息；每周至少半天休息由复盘记录。
- 手动记录可随时保存，包括如实补记在边界外发生的学习。计划参考分钟不会自动填入实际量。
- 不生成补量任务，不设置连续打卡惩罚或硬性完成率，不要求十周学完高数。
- 周末数学长块可主动暂停分段，休息时必须暂停；计时器不能判断人是否真实在学习。

## 数据与备份

数据保存在应用私有目录。v1.1.0新增网络权限，仅由原生代码通过HTTPS获取图文素材；学习数据不用于素材请求。网页界面、字体和脚本打包在APK内，WebView不直接加载互联网页面，也不扫描手机文件。

导出备份通过Android系统文件选择器保存ZIP，内容包括计划、参考量、实际记录、周复盘、提醒设置、已完成的计时会话、全部图文、实际图片、日签与开屏历史、收藏和去重记录。运行中尚未结束的计时不包含在备份里。

恢复前会检查文件格式、字段、日期、图片摘要和清单，并显示计划日期、记录天数与图文条数。确认恢复完整ZIP后替换学习数据、图文历史和收藏；请先导出当前数据。旧版v1.0.0 JSON仍可导入，只替换学习数据，保留已有图文。必须结束当前计时才能导入。恢复使用日志保护两份状态文件，异常中断时可回滚原数据。卸载或清除应用数据会移除本地记录，换机前需要导出完整备份。

桌面小组件显示今日实际/参考和状态，点击打开APP。可从设置请求添加，或长按桌面空白处进入“小组件”选择“每日学习”。

系统可能延迟普通学习提醒；该版本采用非精确提醒，触发时会再次检查休息边界，迟到过久直接略过。在vivo设备上，如系统省电策略终止应用，需以实际情况核对时间；可在系统中按个人需要允许后台运行。

## 构建

不依赖云端学习数据库或在线前端库。APK使用Java原生宿主、前台计时服务、系统提醒、小组件和媒体管理；界面HTML/CSS/JS打包在APK内。打卡和已经缓存的图文可以离线使用，第一次取得图片及新增素材需要联网。

本机已有JDK21与Android SDK36，使用以下命令直接构建：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
node --test .\tests\model.test.cjs
```

`build.ps1 -TestBuild` 会额外生成可调试的测试APK，含Android仪器测试；正式APK不带测试入口且关闭WebView调试。

个人安装签名保存在 `.signing/personal-release.p12`，不包含在源码分享包中；保留该文件便于后续直接覆盖升级，避免卸载丢数据。源码构建自动生成新的个人签名时，不能直接覆盖不同签名的旧安装，应先备份数据。

原始参考数据来自上级目录 `output/每日打卡表_独立会话交接说明.md`。`generate_seed.py` 提取原文70日数据，并核对日期连续性及十周逐项合计；不写入实际记录。

验证结果与截图保存在 `docs/`，正式安装包和SHA256在 `dist/`。
