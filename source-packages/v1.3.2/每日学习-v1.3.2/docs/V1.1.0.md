# v1.1.0开发与验证说明

开发与测试日期：2026年10月13日；交付日期：2026年10月14日。设备目标：vivo X100s / Android 16；本机验证使用Android 16、API 36模拟器。

## 本版功能

- 重新启动随机显示一张图文，图片就绪后展示5秒，可立即跳过。后台返回、开屏中切后台、文件选择器和分享面板返回均直接进入原页面。
- 日签每天抽取一次，当天固定；多次点击、进程重启和离线回看不会换卡。日期以手机本地日历为准。
- 日签历史、开屏回看和收藏分别显示；原文及外文中文释义保留完整，长文在详情滚动阅读。
- 保存完整图文到相册、打开系统分享面板；长文分成可读字号的多张图片，保留页码、日期和来源。
- ZIP完整备份包含学习数据、实际图片、图文历史、收藏和去重记录；兼容旧版v1.0.0 JSON学习备份。
- 与v1.0.0使用相同包名和安装签名，versionCode由1升为2。学习数据模型仍为version:1，覆盖升级保留原有记录。

## 用户后续要求的落实

★ 取消离线插画方案。正式APK不包含内置日签图片，也不生成本地程序插画。照片通过Lorem Picsum获取，艺术作品通过Met开放藏品API获取；两者都记录来源及作者。图片正常下载后保存为本地缓存，缓存用于历史和断网回看。

来源及核查规则详见 [插图来源与选择核查](插图来源与选择核查.md)。下载后检查JPEG/PNG签名、结尾、实际解码、尺寸和SHA256；Met每次检查公共领域标记。图片与文字分别检查展示历史，不通过改色、撒点或重新配文字来制造全新图片。

首次完全没有图片时，展示可跳过的获取状态，等待最多8秒后进入学习页面；取得完整图文后正常展示5秒。没有图片时不消耗当天抽签资格。日签需要新图片而素材未就绪时异步联网获取，用户可以继续使用APP；失败后允许重试。

有未展示图文时优先使用；无法取得新图片且已有真实图片缓存时，选择较久未展示的缓存图片并标记复用。有限缓存不保证永不重复。图文允许独立搭配，不保证每一组都语义配套。

文字优先使用一言中文语句，并保留81段AI辅助原创文字作补充，其中25段外文已有中文释义。未接入付费AI接口或实时任意语言翻译；没有中文释义的外文候选不能进入抽取池。

## 备份与图片安全边界

- WebView界面与脚本仍打包在APK内，WebView本身阻断互联网加载；只有原生HTTPS取图代码可以访问支持来源。
- 分享通过只读ContentProvider授予目标应用临时读取权限，无法借分享URI读取学习记录或改写图片。
- ZIP导入限制文件路径、体积和图片清单，并核对图片摘要；不能通过压缩包路径写入任意私有文件。
- 两份状态的完整恢复保留回滚日志；异常中断后恢复原始状态。正在运行的学习计时仍需先结束再导入。
- 图文数据独立存储，不把学习计划、实际分钟或复盘发给素材来源。

## 实际限制

vivo X100s真机尚未连接。本版验证可以确认Android 16模拟器上的行为，不能代替手机自身的网络、相册、系统分享或省电策略实测。公开素材服务可能临时不可达；首次无图片或无新素材时按照上述获取状态和缓存规则处理。

源代码、使用说明、版本说明、正式APK及SHA256交付到learning/output/android。安装签名私钥保留在项目本地.signing目录，不包含在分享的源码ZIP中。
