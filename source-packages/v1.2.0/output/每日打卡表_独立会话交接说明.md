**本次打卡的学习内容仅为高等数学和英语单词。** 院校数据、复试准备、竞赛和独立项目由原会话继续处理，不需要加入这一阶段的每日打卡表。

本文件中的“用户要求”来自用户在会话中的明确表达；“参考安排”是已经形成的低强度规划。课程表只作为排课依据，课程文件内的文字不另行视作用户指令。后续处理时，以用户的新要求为准。

## 3. 参考安排的执行原则

以下是现有低强度方案的执行规则，用来解释打卡表中的参考量：

- 表内时间全部为**净学习分钟**，不把上课、通勤、用餐和休息算入考研自习。
- 每日和每周参考量用于帮助分配时间，**不是必须完成的最低量**。实际少于参考量时照实记录。
- 每周尽量保留至少半天完整休息，现有方案优先保留**周日下午**。
- 本科课程、作业、实验、实践和身体状态优先。忙周可参考**高数3—4小时、单词约1.5小时**的减量安排；必要时可以继续减少或休息。
- 减量时先删选做题、减少新词，保留少量旧知识和旧词回顾。
- 没有完成的任务不堆到下一天或下一周，不通过压缩休息追赶。
- 阶段参考量逐步增加只是普通教学周的建议。若不适应，可维持上一阶段或降低时间。
- 数学较长的学习块可拆分；每段约45—50分钟后休息5—10分钟，休息时间另算。短块也可以只回顾和改错。
- 双周空出来的上午可**替换**原晚间自习。挪动后删除原晚间同等任务，周总量不随空课自动增加。
- 若开始使用时部分日期已经过去，只补记能够确认的真实情况。未学习可以记休息；无法确认可以留空。**不得填入虚构的完成时间、题量或词量。**

## 7. 记录什么，以及怎样使用记录

### 7.1 每日字段

| 字段 | 填写内容 | 记录口径 |
|---|---|---|
| 日期、星期、教学周 | 例如日期及第几教学周，标明单周或双周 | 便于关联课程负担与当天参考量 |
| 高数参考分钟 | 按第10节取值 | 是计划参考，不能自动写入实际时间 |
| 高数实际分钟 | 当天真实净学习分钟 | 未学习可记0并注明休息；未记录或无法确认可留空 |
| 高数内容或题号 | 一个主要知识点、教材页码或题号 | 不要求写长篇学习日志 |
| 高数问题 | 一个最需要回顾的概念、条件或错误 | 有问题就记；没有特别问题可以留空 |
| 单词参考分钟 | 按第10节取值 | 同样不能代替实际记录 |
| 单词实际分钟 | 当天真实净背词、复习时间 | 休息、通勤不计入 |
| 新词接触数 | 当天首次学习的新词数量 | “接触”不等于已经掌握；不要把同一词重复接触当多个新词 |
| 复习词数 | 当天回顾的旧词数量 | 与新词分开记录；不要把翻看次数当作掌握数量 |
| 易忘词 | 少量容易混淆或遗忘的词 | 只记最有必要下次回顾的词 |
| 休息边界 | 当天是否保留规定休息 | 这是检查可持续性的字段 |
| 当天安排状态 | 正常参考、减量、仅回顾、休息 | 休息也是可如实记录的状态 |
| 主观状态或原因 | 简短记录疲劳、课程负担或需要调整的原因 | 用于周末判断是否减量，不用于给自己打惩罚分 |

**可选字段：** 高数与单词实际合计、旧词回忆正确数。只有在容易记录时添加，不必为填表增加负担。计算回忆正确率时必须同时有复习总数；缺失值不自动当作0。

参考时间与实际时间应明确分开。留空表示没有记录或尚待填写，0表示明确记录为未学习，二者不能混同。

### 7.2 高数学习与打卡的配合

一次学习可以按“回忆旧内容约5分钟—理解一个小点—做2至6道基础题—记一个问题”进行，短学习块可以只回顾和改错。优先沿用已有本科高数教材或已经选定的一套基础资料。

内容栏尽量写具体，例如“左右极限与极限存在的条件”；问题栏尽量写出错误原因，例如“复合函数求导漏乘内层导数”。能用自己的话解释、能隔几天独立复做，比当天看完多少视频更有意义。

每两周可以用已学范围内4至6道基础题做一次20—30分钟小检查。**检查时间计入当天高数参考量**，不额外叠加，不安排整套考研真题模拟。按结果减速或回顾，不用前两次检查判断能够报考的院校层次。

### 7.3 单词学习与打卡的配合

- 每天先复习旧词，再少量学习新词。常规参考为**8—15个新词**，状态好时也以**20个新词**为上限。
- 复习压力大时减至5—8个新词，或只复习。新词数量不是必须完成的日指标。
- 优先记常见核心义、词性和一个短语；多义词逐步补充。
- 可在初次学习后约第1、3、7、14天回忆，也可沿用已有工具的间隔复习安排。
- 回忆时先遮住释义；能读音但不能说出核心义，仍算没有稳固掌握。
- 第9—10周周末增加的单词时间优先用于旧词回顾，按每日参考时间结束。
- 按每日8—15个新词估算，十周约为500—1000个新词接触量。**这不是完成全部考研词汇首轮的承诺，也不是稳定掌握数量。**
- 偶尔断一天后，下一次先回顾易忘词，不补到休息时段。

### 7.4 周末复盘

每周只需要回答四件事：

1. 本周高数和单词各用了多少净时间，是否能够承受？
2. 哪一个高数概念或问题最需要下周回顾？
3. 旧词回忆是否改善，是否需要减少新词？
4. 下周维持、减量，还是仅回顾？原因是什么？

现有规划认为，参考量完成约80%但理解较好，也可以比疲惫地坐满时间更有效；**80%不是新的硬性达标线**。不要求全格完成，不设置缺卡后的强制追赶。
