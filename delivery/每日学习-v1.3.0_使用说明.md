# 每日学习 v1.3.0 使用说明

**安装与版本**

手机首次覆盖安装「每日学习-v1.3.0.apk」。最低 Android 8.0，目标设备 vivo X100s / Android 16。版本在「设置 → 关于」查看，来自已安装包的元数据。

更新前可在旧版导出备份，再覆盖安装。保留旧安装，覆盖更新无需卸载；卸载会删除应用数据。

后续打开「设置 → 关于 → 检查更新」，查看新版说明，点击「下载更新」。下载完成后点击安装，按系统提示允许此 App 安装应用并确认；从权限设置返回后再点击安装。安装前保存页面输入，结束并保存当前计时，或确认丢弃。取消安装仍可回到 App，再次点击安装。

电脑发布后，手机通过同一入口检查和下载，不再需要手动传送 APK。发布和下载使用 GitHub Release；手机当前网络需能访问 GitHub。正在使用的版本以「关于」为准。

**记录与计时**

今日页显示「参考时长」「已记录」与科目记录数。空白显示「未记录」，填入 0 显示「0 分钟」；一科填 0、另一科空白显示「1/2 科目已记录」。选择休息不自动改变实际分钟。

输入分钟或随记后点击「保存这一天」。显示「已保存」才完成保存；失败时输入保留，可点击「重试」。复盘与计划编辑使用各自保存按钮。

点击科目的计时按钮开始；可暂停、继续、结束并保存，或确认丢弃。暂停时长不计入学习时间。工作日 20:30 起、周末 09:30 前和 19:00 起停止学习计时，到边界自动暂停。详细边界在「设置 → 休息时段」。手动补记不受计时边界限制。

计划可编辑日期、参考分钟、周目标并新增科目；复盘显示实际记录与参考时长，历史统计口径沿用原版。

**日签**

重新启动时展示随机图文 5 秒，可跳过；从后台返回直接进入原页面。每天抽取一个日签，当天固定，可在日签页收藏、回看历史、保存图片或打开系统分享面板。文字与图片分别署名；外文附中文释义，完整出处在「来源」。

图片仍通过联网取得真实照片或公开艺术作品，已有历史使用原图片回看。「联网准备素材」「准备新图文」和「清理未使用素材」在日签页；清理不删除已展示图文及收藏。

**提醒、备份与桌面**

在设置主动开启学习提醒后处理系统通知权限，并保存时间；未授权时可从「打开通知设置」进入系统设置。「未收到提醒？」提供调度限制说明。关闭开关后保存即可关闭提醒。

「导出备份」选择保存位置；「从备份恢复」选择 ZIP 完整备份或旧 JSON。恢复前会校验，并明确将替换的内容，确认后执行；取消不覆盖。完整 ZIP 包含学习与图文，旧 JSON 只替换学习内容。当前计时需先保存或确认丢弃。

「添加到桌面」发起系统小组件请求，在系统页面确认添加；仅确认成功后显示「已添加到桌面」。手动添加方式在「添加帮助」。

验证报告及更新截图见 [v1.3.0开发与验证说明](每日学习-v1.3.0_资料/V1.3.0.md)，既有文案对照见 [文案审计](每日学习-v1.3.0_资料/ux-copy-audit.md)。真机安装、语音阅读、vivo 后台调度需在实际手机确认。
