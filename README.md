# 每日学习：历史源码与交付归档

当前开发源码见 [main](https://github.com/gaspainting/daily-study/tree/main)。本分支收录本机v1.0.0至v1.3.3的源码ZIP、验证ZIP内容和各版交付文件，原ZIP路径保留。

- source-packages/：7个版本的源码包内容。
- verification-packages/：5个版本的验证资料包内容。
- delivery/：各版正式APK、摘要、说明和交付核对。
- archive-manifest.json：原ZIP摘要与每个归档文件的字节数、SHA256。

所有文件与本机原包逐项比较。原私钥、临时设备快照及构建缓存留在本机。已发布的APK资源和版本标签继续保留。归档提交日期为本次导入时间。
