# 每日学习 v2.0.0 设计系统

这是 Android 原生 Activity + WebView 的移动学习记录界面规范。业务数据、schema 9、正式保存和自动评估继续由现有模块负责；本文件只定义视觉和交互层。

## 方向

- 清晰、安静、可持续记录。信息层级优先于装饰，重要操作靠近其影响对象。
- 浅色、深色、跟随系统三种外观；主题偏好只保存在界面偏好中，不写入学习数据。
- 采用 Material 的触控、组件和系统衔接原则，吸收 HIG 的直接操作、清楚反馈和恢复路径。
- 动效只表达状态变化，保留 `prefers-reduced-motion` 路径；不使用 emoji 作为图标。

正文文字以 4.5:1 对比度为目标；状态同时使用文字和结构线索，不依赖颜色单独传达。

## 排版和间距

- 使用系统无衬线字体；标题使用较高字重和紧凑字距，正文保持舒适行高。
- 触控目标至少 44px；Android 真机验收目标为 48dp。
- 常用间距为 8、12、16、18、24px；模块使用 16—18px 圆角，输入和按钮使用 10—12px 圆角。
- 100% 和 200% 系统字号都必须保留字段、单位、主操作和错误位置。

## 组件

- 页面顶部显示产品标识和当前计划；计划切换继续使用原有入口。
- 底部五项导航固定为“今日、计划、复盘、日签、设置”，当前页使用背景和文字共同标识。
- 模块以表面、细边框和轻阴影分组；重要状态使用浅色语义背景。
- 主按钮使用蓝色填充，次要操作使用表面按钮，文本操作使用蓝色文字。
- 输入、选择和文本域保留可见标签；保存显示处理中、成功或错误结果，错误提供可执行的重试路径。
- 编辑器和弹层使用底部表面，返回后恢复焦点；不改变现有草稿和正式保存语义。

## 页面范围

今日、计划、复盘、日签、设置共同使用这套颜色角色、卡片、标签、导航和状态规则。v2.0.0-beta.1 先覆盖主题、公共组件、导航、今日、计划和核心编辑器；beta.2 再补齐复盘、日签、设置、手册、导入和更新页面。

## 验收

- 375px、768px、1024px 和较宽窗口无横向溢出。
- 键盘出现后当前输入和保存仍可达；返回顺序和焦点可预测。
- 空白、0、部分记录、草稿、处理中、失败、成功、休息和单位不一致分别呈现。
- 低动态设置下仍可完成导航、编辑、保存和错误恢复。
